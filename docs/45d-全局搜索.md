## 一、目标

FarmAppBar 加搜索入口 → 搜索页双区结果：

1. **功能导航区**（前端本地匹配 `feature_catalog`）：输「补贴」→ 命中「补贴申请」功能 → 点击直达 `/policy/service`
2. **内容结果区**（后端 `GET /search`）：政策 / 农技 / 商品 / 招工 / 课程 的具体条目

## 二、后端接口（已有，不新增）

```json
{
  "keyword": "玉米",
  "total": 12,
  "policy": [{ "id", "title", "summary", "level", "category" }],
  "disease": [{ "id", "diseaseName", "cropType", "category" }],
  "product": [{ "id", "title", "price", "unit", "category" }],
  "job": [{ "id", "title", "company", "salary", "jobType" }],
  "course": [{ "id", "title", "category", "instructor" }]

```

可带 `&type=policy` 限定单类。

### 2. 新建 `app/lib/pages/search/search_page.dart`

```dart
class SearchPage extends StatefulWidget { ... }

class _SearchPageState extends State<SearchPage> {
  final _ctrl = TextEditingController();
  final _focus = FocusNode();
  String _query = '';
  bool _loading = false;
  Map<String, dynamic> _content = {};   // 后端 /search 结果

  @override
  void initState() {
    super.initState();
    WidgetsBinding.instance.addPostFrameCallback((_) => _focus.requestFocus());
  }

  // 本地功能匹配
  List<FeatureItem> get _featureHits {
    if (_query.isEmpty) return const [];
    final q = _query.toLowerCase();
    return kFeatureCatalog.where((f) =>
      f.name.toLowerCase().contains(q) ||
      f.keywords.any((k) => k.contains(q) || q.contains(k))
    ).take(8).toList();
  }

  Future<void> _searchContent() async {
    final q = _ctrl.text.trim();
    if (q.isEmpty) return;
    setState(() { _query = q; _loading = true; });
    try {
      final data = await ApiClient.get('/search', query: {'keyword': q});
      if (!mounted) return;
      setState(() {
        _content = data is Map ? data.cast<String, dynamic>() : {};
        _loading = false;
      });
    } catch (e) {
      if (!mounted) return;
      setState(() => _loading = false);
      // 内容搜索失败不影响功能匹配区，静默
    }
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      backgroundColor: AppColors.background,
      appBar: AppBar(
        backgroundColor: AppColors.surface,
        elevation: 0,
        leading: IconButton(icon: const Icon(Icons.arrow_back, color: AppColors.onSurface),
          onPressed: () => context.canPop() ? context.pop() : context.go('/home')),
        titleSpacing: 0,
        title: Container(
          height: 40,
          padding: const EdgeInsets.symmetric(horizontal: 12),
          decoration: BoxDecoration(color: AppColors.surfaceLow, borderRadius: BorderRadius.circular(999)),
          child: Row(children: [
            const Icon(Icons.search, size: 20, color: AppColors.outline),
            const SizedBox(width: 8),
            Expanded(child: TextField(
              controller: _ctrl, focusNode: _focus,
              textInputAction: TextInputAction.search,
              decoration: const InputDecoration(hintText: '搜索功能、政策、农技、商品...', border: InputBorder.none, isDense: true),
              onChanged: (v) => setState(() => _query = v.trim()),   // 功能区实时
              onSubmitted: (_) => _searchContent(),                  // 内容区提交触发
            )),
            if (_query.isNotEmpty)
              GestureDetector(onTap: () { _ctrl.clear(); setState(() { _query = ''; _content = {}; }); },
                child: const Icon(Icons.close, size: 18, color: AppColors.outline)),
          ]),
        ),
      ),
      body: ListView(
        padding: const EdgeInsets.fromLTRB(16, 12, 16, 28),
        children: [
          if (_query.isEmpty) _hotKeywords(),         // 空态：热门词
          if (_featureHits.isNotEmpty) ...[
            const SectionTitle('功能'),
            _featureGrid(_featureHits),
          ],
          if (_loading) const Padding(padding: EdgeInsets.all(24), child: Loading(text: '搜索中')),
          if (!_loading && _content.isNotEmpty) ..._contentSections(),
          if (!_loading && _query.isNotEmpty && _featureHits.isEmpty && _contentEmpty)
            const Padding(padding: EdgeInsets.all(40), child: EmptyView('没有找到相关结果')),
        ],
      ),
    );
  }
  // _hotKeywords: 几个推荐词 chip（补贴/行情/病虫害/农机/天气），点击填入并搜索
  // _featureGrid: FeatureItem 列表 → 点击 context.go(f.route)
  // _contentSections: 政策/农技/商品/招工/课程 各一小节，点条目跳对应板块
  // _contentEmpty: _content 各数组都空
}
```

要点：
- **功能区实时**（onChanged）：每输入即本地过滤 catalog，零延迟
- **内容区提交触发**（onSubmitted / 搜索按钮）：调后端，避免每个字符打一次接口
- 空态显示热门关键词 chip
- 功能条目点击 → `context.go(f.route)`
- 内容条目点击 → 跳对应板块（policy→/policy, disease→/agri, product→/market, job→/life, course→/policy/service）

### 3. FarmAppBar 加搜索入口

`app/lib/widgets/common.dart` 的 `FarmAppBar` actions 默认加搜索图标：

```dart
actions: actions ?? [
  IconButton(
    icon: const Icon(Icons.search, color: AppColors.onSurfaceVariant),
    onPressed: () => ... ,   // 见下
  ),
  IconButton(onPressed: onBell ?? () {}, icon: const Icon(Icons.notifications_none, ...)),
],
```

问题：FarmAppBar 是无状态通用组件，没有 context.go 能力 —— 用传入的 BuildContext：

```dart
// build 内已有 context
IconButton(
  icon: const Icon(Icons.search, color: AppColors.onSurfaceVariant),
  onPressed: () => GoRouter.of(context).go('/search'),
),
```

> 注意：当调用方传了自定义 `actions` 时，搜索图标会被覆盖。给 FarmAppBar 加一个 `bool showSearch = true` 参数，自定义 actions 时把搜索图标 prepend：
> ```dart
> actions: [
>   if (showSearch) IconButton(...搜索...),
>   ...(actions ?? [默认铃铛]),
> ],
> ```
