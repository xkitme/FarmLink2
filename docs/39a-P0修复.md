## F1 · setState after dispose 守卫

**文件**：`app/lib/pages/data/data_service_page.dart`

`_load()` 的 catch 块中，原先在 `if (!mounted) return;` 之后还有两个
`OfflineCache.readList` 异步调用，最终 setState 没有再次检查 mounted，
存在用户在 cache 读取期间退出页面 → setState on disposed State 的崩溃路径。

**改动**：

```dart
} catch (e) {
  if (!mounted) return;
  final annual = await OfflineCache.readList('data_annual_report');
  if (!mounted) return;      // ← 新增
  final stat = await OfflineCache.readList('data_stat_report');
  if (!mounted) return;      // ← 新增
  setState(() { ... });
}
```

同文件 `_generateAnnualReport()` 的 `await _load()` 后追加 `if (!mounted) return;`，
再走 `_showAnnualReport`，避免 sheet 在 disposed State 上拉起。

其它 async 函数 `_openStatForm` / `_openSyncLogs` / `_load` 主分支均已有
mounted 检查或函数末尾直接结束，无需追加。

## F2 · 农机占位禁用 + 角标

**文件**：`app/lib/pages/machinery/machinery_page.dart`

原 `_fallback` 用真实型号「雷沃欧豹 M1004」，且「立即预约」按钮无条件可点，
点击后只 toast 不进入 loading，用户误以为应用故障。

**改动**：

1. `_fallback` 列表：
   - `name: '雷沃欧豹 M1004'` → `'示例农机 · 资料更新中'`
   - `type: '100马力 轮式拖拉机'` → `'100 马力 · 轮式拖拉机'`
   - `owner: '李师傅'` → `'示例机主'`

2. 卡片标题右侧 `Icons.verified` 在 `machine.id == null` 时替换为
   `StatusChip('暂未上架', color: AppColors.outline)`，给出明确视觉信号。

3. 「立即预约」按钮：
   ```dart
   onPressed: (_booking || machine.id == null) ? null : () => _bookMachine(machine),
   ```
   占位机直接置灰，不再走 toast 路径。

## F3 · 集市占位 CTA 置灰

**文件**：`app/lib/pages/market/market_page.dart`

原 `_showProductDetail` 的「加入合计」按钮无条件 `Navigator.pop` + `_addCart`，
而 `_addCart` 在 `product.id == null` 时只 toast 不入车，造成「按了像加成功
其实没加」的假象。

**改动**：

1. 商品卡片左上角 badge：在 `product.id == null` 时颜色改 `AppColors.outline`、
   文字改 `'示例'`，与真实商品的「新鲜 / 直采 / 限量」状态分离。

2. detail sheet 头部：`StatusChip(product.badge, color: product.badgeColor)`
   在 `product.id == null` 时显示 `'示例商品'`。

3. 「加入合计」按钮：
   ```dart
   onPressed: product.id == null
       ? null
       : () { Navigator.pop(context); _addCart(product); },
   label: Text(product.id == null ? '资料更新中' : '加入合计'),
   ```
