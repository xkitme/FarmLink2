# 分段 102 — 语音助手 TTS 重复播报修复

> 执行日期：2026-06-19

## 目标

修复语音助手同一条最终回复被 TTS 播放两遍的问题。

## 根因与修复

- 首轮 `_applyAssistantResponse` 执行命令后会调用 `/assistant/command-result`。
- 命令回执再次递归进入 `_applyAssistantResponse` 并播报；递归返回后外层又播报一次。
- 新增 `speakAfterCommands` 控制：命令回执只更新最终屏幕文案，不播报；最外层在全部命令
  和回执完成后统一播报一次，然后恢复麦克风监听。
