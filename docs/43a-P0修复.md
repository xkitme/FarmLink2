# 分段 43a — P0 修复

> 落地分段 42 review 清单的 P0 三项：G1 / G2 / G3。
> 本批只处理运行时回归和产品口径风险，不扩大到 43b / 43c。

## 一、目标

- 队列失败 detail 为空字符串时仍能显示兜底诊断。
- 同步日志 sheet 内点击「立即同步」时，按钮 loading 和本地队列列表能即时刷新。
- 通用错误重试组件默认恢复为中性图标，避免把业务失败暗示为连接问题。

## 二、实施备注

### G1 · detail 空串兜底

文件：`app/lib/core/offline_sync_queue.dart`

新增 `_detailOr(detail, fallback)`：

```dart
static String _detailOr(String? detail, String fallback) {
  final normalized = detail?.trim();
  return normalized == null || normalized.isEmpty ? fallback : normalized;
}
```

`flush()` 中 `conflict` 与 `failed` 分支均改用该方法：

- `CONFLICT`：空 detail 回退到 `服务端数据更新，需要人工合并`
- `FAILED`：空 detail 回退到 `同步失败`

这样服务端返回 `detail: ''` 时不会把 `lastError` 写成空字符串。

### G2 · 同步日志 sheet 响应父级状态

文件：`app/lib/pages/data/data_service_page.dart`

父页面新增两个共享状态：

- `_localQueueNotifier = ValueNotifier<List<SyncQueueItem>>([])`
- `_flushingNotifier = ValueNotifier<bool>(false)`

改动点：

- `_load()` 成功和失败分支都会同步更新 `_localQueueNotifier.value`
- `_flushQueue()` 开始 / 结束时同步更新 `_flushingNotifier.value`
- `_SyncLogsSheet` 不再接收静态 `localQueue` / `flushing`
- sheet 内使用双层 `ValueListenableBuilder` 监听队列和同步状态

结果：

- sheet 内「立即同步」点击后按钮会马上切到 `同步中`
- 同步完成后本地队列列表会随 `_load()` 结果刷新
- 不再依赖关闭 sheet 才看到最新状态

### G3 · ErrorRetry 默认图标恢复中性

文件：`app/lib/widgets/common.dart`

`ErrorRetry.icon` 默认值从：

```dart
this.icon = Icons.cloud_off
```

改为：

```dart
this.icon = Icons.error_outline_rounded
```

并更新注释：默认使用中性错误图标，确认是连通性场景时调用方可显式传 `Icons.cloud_off`。
