# 分段 29 — 本机一键启动脚本升级

- 已检查现有 `scripts/start-local.ps1`、`README.md`、后端与管理面板 `package.json`。

## 本次完成内容

1. 新增根目录入口 `start.bat`，在项目根目录运行一条命令即可启动全部本机服务：

```powershell
.\start.bat
```

2. 升级 `scripts/start-local.ps1`：
   - 启动后端 API，默认端口 `8000`。
   - 启动 Ant Design Pro 管理面板 Vite 服务，默认端口 `5173`。
   - 构建并启动 Flutter Web 静态服务，默认端口 `5000`。
   - 启动前自动清理对应端口上的旧进程。
   - 所有服务日志写入 `.runtime/`。
   - 启动摘要写入 `.runtime/start-summary.txt`。
   - 支持 `-SkipWebBuild`、`-SkipAdmin`、`-SkipMobile`。
   - 支持 `-BackendPort`、`-AdminPort`、`-WebPort` 自定义端口。
3. 调整 `backend/admin/vite.config.js`，管理面板开发代理跟随 `FARMLINK_BACKEND_PORT`，不再固定代理到 `8000`。
4. 更新 `README.md` 快速开始说明，明确一键启动后的三个访问地址。

## 访问地址

- 后端 API：`http://localhost:8000/api/v1`
- 管理面板：`http://localhost:5173/admin/`
- 移动端 Web：`http://localhost:5000`
