## P0 · 收尾欠债（小、当下绕脚，建议先清）

### 58-1 · 日期弹层中文化（i18n）
- **现状**：`showDatePicker` 弹层是英文（农机预约等所有日期选择受影响）。根因：`app/lib/main.dart` 的 `MaterialApp` 没配 `localizationsDelegates` / `supportedLocales`。
- **做法**：`pubspec.yaml` 加 `flutter_localizations`（sdk）；`main.dart` 两个 `MaterialApp`/`MaterialApp.router` 都加：
  ```dart
  localizationsDelegates: GlobalMaterialLocalizations.delegates,
  supportedLocales: const [Locale('zh'), Locale('en')],
  locale: const Locale('zh'),
  ```
- **验收**：农机预约日期选择器为中文。
- 工作量：S。无依赖。

### 58-2 · G9 dashboard AI 调用数口径 —— **决定：现状接受 / 暂不修**
- **问题**：`dashboard.aiCallCount` 现按用户实时 `count()`，删 record 后回落。
- **决定（Claude 拍）**：**暂不修**。这是装饰性的 per-user 指标，用户删自己历史时数字跟着降属合理/符合预期；为它加软删字段或计数表（改 schema + 活库迁移 + 所有列表查询带 `deletedAt`）性价比太低。
- **何时再做**：仅当「ADMIN 需要全平台累计运营指标」出现时，走方案 B（新增 `PlatformCounter` 表 + create 时 +1 + dashboard 读累计 + 一次性回填）。在那之前不动。
- 工作量：0（现状）。

### 58-3 · 「进已有对话首次发送重触发进入动画」回归排查
