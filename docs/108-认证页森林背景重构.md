# 108 - 认证页森林背景重构

## 目标

参考用户提供的森林系登录图，重构登录、注册、忘记密码三页为统一的全屏背景认证体验，并让认证背景通过独立公开 API 获取。

## 改动

### 后端

- 新增 `GET /api/v1/site/auth-background`：
  - 公开读取认证页背景。
  - 返回 `imageKey=auth-hero`、`imageUrl=/uploads/site/auth-hero.jpg`、`fallbackAsset`。
- 继续复用既有站点图上传机制，管理员仍通过站点配图页替换 `auth-hero`。
- 管理台站点图标签改为“登录/注册/忘记密码页背景”。

### Flutter App

- 新增 `app/lib/pages/auth/auth_widgets.dart`：
  - `AuthBackgroundImage`：优先请求 `/site/auth-background`，失败时回落 `/uploads/site/auth-hero.jpg`，再失败回落 bundled asset。
  - `AuthScreenScaffold`：全屏背景、深色遮罩、居中品牌和共用返回按钮。
  - `AuthTextField` / `AuthPrimaryButton` / `AuthInlineAction`：统一认证输入框、主按钮和底部跳转。
- 重构三页：
  - `login_page.dart`：改为参考图式全屏登录，保留协议勾选、忘记密码、注册入口。
  - `register_page.dart`：改为同款背景与输入框，并把校验收敛到 `Form`。
  - `forgot_password_page.dart`：改为同款背景与四输入框布局。
- 左上角返回按钮改成 64×60 透明命中区，避免被全屏滚动层或边缘点击影响。
- `auth-hero.jpg` 使用干净山林村落图作为背景源；用户提供参考图本身包含登录 UI，不直接作为背景，避免表单重影。

## 实施备注

- 背景 API 与旧 `/site/images` 并存；认证页不再直接依赖全量图片清单。
- 参考图用于视觉结构、层次和输入框风格，不直接作为背景素材，因为原图已包含 UI。
