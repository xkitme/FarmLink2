# 田园通 · 项目介绍

## 项目定位

田园通是一套面向乡村的数字乡村助农平台，围绕国家「乡村振兴」战略与「数字乡村」建设方针而设计，为农户提供从农业生产、农产品流通、农机共享、气象灾害、惠农政策到乡村生活的一站式数字化服务。

平台将原本分散在各处的涉农服务整合到统一的移动端应用与后台系统中，核心理念为：**智能农业云平台 · 数据协同 · AI 赋能**。

---

## 解决的问题

当前乡村数字化服务普遍分散：查行情、报灾情、申请补贴、采购农资往往分属不同渠道，农户使用门槛高。田园通针对这一痛点提供整合方案：

- **一站式服务**：农户在单一应用内即可完成生产、销售、农机、防灾、政策、生活等多类事务；
- **降低使用门槛**：面向不擅长文字输入或年长的用户，提供语音交互、语音操作与适老大字模式；
- **AI 辅助决策**：通过 AI 协助完成病虫害识别、政策问答、产量预测、营销文案生成等任务；
- **多角色协同**：农户、种植大户、村委、农技员、商家、管理员各有对应权限，村委数据按区域隔离。

## 系统组成

| 组成部分 | 职责 | 技术栈 |
|---|---|---|
| **后端服务** | 系统核心，承载全部业务数据与接口，并负责 AI 能力编排 | Node.js + Express + Prisma + SQLite |
| **管理面板** | 网页后台，用于数据管理、接口开关、在线调试与系统监控 | Ant Design Pro（React + Vite） |
| **移动端 App** | 农户使用的主应用，可编译为网页预览或打包为 Android APK | Flutter |

后端处于中心位置，移动端 App 与管理面板均通过接口连接后端。

```
   移动端 App (Flutter)        管理面板 (React)
            \                      /
             \    HTTP / SSE      /
              \                  /
            后端服务 (Node.js + Express)
              /                  \
        Prisma + SQLite       AI 编排 (Ollama + RAG + 规则引擎)
```

## 技术选型

| 层次 | 选型 | 说明 |
|---|---|---|
| 后端框架 | Node.js + Express | 轻量、启动快、易于部署 |
| 数据库 | SQLite（单文件） | 免安装、无需 Docker，便于交付 |
| ORM | Prisma 5 | 类型安全，便于管理表结构 |
| AI 运行时 | Ollama | 本地大模型：qwen2.5（问答）/ bge-m3（向量）/ minicpm-v（图像识别） |
| 鉴权 | JWT 双 Token | access 2 小时 + refresh 30 天 |
| 管理面板 | Ant Design Pro · React 18 · Vite | 成熟的中后台框架 |
| 移动端 | Flutter 3 | 一套代码同时产出 Android APK 与 Web 预览 |
| 移动端状态 / 路由 | Provider + go_router | 管理登录态与缓存；声明式路由并带登录守卫 |

## 关键设计

- **AI 能力具备弹性**：安装 Ollama 时使用真实大模型；模型不可用时自动降级到 SQLite 知识库与规则引擎，接口仍返回可用结果，保证功能不中断。
- **数据可离线缓存、联网同步**：农事记录、灾情上报、动态发布等写操作进入待发送队列，服务端基于时间戳进行冲突检测后汇总。
- **角色与区域隔离**：系统设有 FARMER、BIGFARMER、VILLAGE、EXPERT、MERCHANT、ADMIN 六类角色，村委角色按区域编码实现行级数据隔离。
- **统一响应格式**：所有接口统一返回 `{ code, msg, data, timestamp, traceId }`，并采用统一错误码（如 40101 未登录、42901 限流、60001 AI 繁忙等）。
- **轻量可交付**：采用 SQLite 单文件数据库，配合一键启动脚本，无需 Docker 依赖即可运行完整系统。
