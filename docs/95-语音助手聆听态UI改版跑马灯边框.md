# 分段 95 — 语音助手聆听态 UI 改版：去中心球 + 跑马灯边框 + 底栏识别文本

> 用户给参考图：唤起 AI 助手时不要中间的渐变大圆球，改成**全屏边框跑马灯**（霓虹彩虹光带绕边流动，颜色从图提取）；底部一行「聆听中…」文字 + 左右两个圆形按钮；识别到文字后「聆听中…」自动替换为识别文本。本段只改前端覆盖层交互与视觉，不动后端、命令白名单、TTS。

## 一、目标

- 激活态去掉 `_largeOrb` 中心大球与 `_edgeGlow` 四边渐变灯带。
- 改为**直角全屏边框跑马灯**：`SweepGradient` 彩虹光带随动画相位顺时针绕边，外发光（模糊）模拟霓虹。
- 底栏：左 sparkle 按钮（提交当前文本）、中「聆听中…」状态文字、右键盘按钮（兜底文字输入），左右按钮为彩虹环 + 白色磨砂底。
- 识别到文字后，中间文字自动从「聆听中…」切换为识别文本（`AnimatedSwitcher` 过渡）。
- 覆盖层要盖住**底部一级导航栏**（边框与底栏延伸到屏幕最底）。
- 提交后清空识别文本，底栏回到「正在理解…→聆听中…」；键盘输入框每次打开为空。

## 二、背景

- 原 `VoiceAssistantLayer` 放在 `ShellPage` 的 `Scaffold.body` 内，而底部导航栏在 `Scaffold.bottomNavigationBar`（兄弟节点）——覆盖层够不到导航栏，故边框/底栏盖不住导航栏。
- 配色取自参考图霓虹光带：薄荷绿/青/蓝/紫/粉/暖琥珀（`_auroraColors`）。

## 三、改动

### `app/lib/widgets/voice_assistant_layer.dart`
- 顶部新增 `const List<Color> _auroraColors`（6 色彩虹高亮）。
- `_glow` 动画控制器从 `repeat(reverse:true)`（1800ms 呼吸）改为 `repeat()`（4200ms 单向循环），驱动跑马灯绕圈。
- 删除 `_edgeGlow` / `_largeOrb` / `_statusBar`，`_overlay` 重写为：透明 `Material` + Stack【点击空白关闭的全屏 GestureDetector｜`IgnorePointer` 包 `CustomPaint(_MarqueeBorderPainter)`｜回复气泡(仅 `_hasReply||_sending` 时)｜底栏 `_bottomBar`】。
- 新增 `_MarqueeBorderPainter`：`RRect`（`Radius.zero` 直角）描边两层——外发光（`strokeWidth*2.4` + `MaskFilter.blur 16`）+ 清晰主描边（`strokeWidth 7`），shader 为 `SweepGradient(transform: GradientRotation(t*2π))`。
- 新增 `_bottomBar`：底部黑色渐变条 + `SafeArea`，左右 `_circleButton`（彩虹 `SweepGradient` 环 + `Color(0xFFEDF1F6)` 磨砂底 + 深色图标），中间 `AnimatedSwitcher` 文本：`识别文本 ?? (发送中?'正在理解…':聆听中?'聆听中…':_status)`。
- 新增 `_promptKeyboardInput`：`showModalBottomSheet` 弹 `TextField`（每次空白起步），发送走与语音相同的 `_submitRecognized` 管线。
- 新增字段 `_hasReply`：收到首轮回复才显示回复气泡，纯聆听态保持图示简洁；`_activate`/`_deactivate` 重置。
- `_submitRecognized` 进入发送态时 `_recognized=''`，治「提交后底栏仍停留在已提交文本」。
- 关闭态小球 `bottom: 92 → 150`，因覆盖层已包住导航栏，抬高避免压在导航栏上。

### `app/lib/pages/home/shell_page.dart`
- `VoiceAssistantLayer` 由 `Scaffold.body` 内层上提为包住**整个 `Scaffold`**（body + bottomNavigationBar），覆盖层才能盖住底部导航栏。

## 四、契约

- 不改后端接口、command 白名单、`_executeCommand` 逻辑、TTS。
- `/ai/assistant/turn`、`/ai/assistant/command-result` 调用与字段不变。
- 交互语义不变：静默自动提交、点击空白关闭、左 sparkle = 立即提交、新增右键盘 = 文字兜底。

## 五、验收

- `flutter analyze lib/widgets/voice_assistant_layer.dart lib/pages/home/shell_page.dart`：No issues found。
- `flutter build web --no-tree-shake-icons`：Built build\web。
- 浏览器实测（localhost:5050 注入 token）：`/home` 渲染正常、关闭态小球可见；激活后底栏「聆听中…」+ 左右彩虹圈按钮显示，且**底栏盖住底部导航栏**（home3 截图确认）。
- 用户实测：跑马灯效果认可；按反馈把圆角改直角、覆盖层盖住导航栏、提交/重开键盘清空文本。
- ⚠️ Playwright 会话因假 token 触发 401 登出，未能跑完整一轮真识别；真语音以用户真机/授权环境为准。

## 六、不在范围

- 不改后端、command 白名单、TTS、DeepSeek 配置。
- 不做真机麦克风连续识别回归（沿用既有 P2 计划）。
- 边框配色未做可配置化，硬编码 `_auroraColors`。

## 七、实施备注

- `SweepGradient.colors` 在 const 上下文不能用 `_auroraColors.first`（`const_eval_property_access`），收尾色改写字面量 `Color(0xFF7CF0BD)`。
- 跑马灯外发光用 `MaskFilter.blur`，配合更宽描边模拟霓虹辉光；直角 `Radius.zero` 贴满全屏。
