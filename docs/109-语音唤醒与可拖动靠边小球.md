# 109 - 语音唤醒（呼叫唤起）与可拖动靠边小球

## 目标

1. **呼叫唤起**：用户说「你好小田」唤起 AI 语音助手；唤醒词可在管理台配置（支持多个）。
2. **小球收敛**：悬浮小球变小、默认位置放低一点。
3. **可拖动只靠边**：小球可拖动，松手只吸到屏幕左/右边缘，位置跨页面与重启都记住。

## 背景

语音助手悬浮小球此前固定在右下角、不可移动，可能遮挡页面内容；且只能点击唤起，不能「免提呼叫」。本次加入唤醒词常听与可拖动小球，提升可达性与免提体验。设计见 `docs/superpowers/specs/2026-06-21-语音唤醒与可拖动小球-design.md`。

## 改动

### 后端
- `ai/services/assistant-config.service.js`：新增 `DEFAULT_WAKE_WORDS=['你好小田']` 与 `normalizeWakeWords()`（数组 / 逗号/换行字符串 → 去空去重数组，≤8 个、单词 ≤20 字，空回落默认）；`normalize()`/`getAssistantConfigView()` 带上 `wakeWords`；`saveAssistantConfig()` 处理 `patch.wakeWords`。
- `ai/ai.controller.js`：新增 `assistantConfig`——移动端公开读取，**只回 `{enabled, wakeWords}`，绝不暴露 key/提示词**。
- `ai/ai.routes.js`：新增 `GET /ai/assistant/config`（`/ai` 下 `requireAuth`）。
- 管理端点 `aiAssistantConfigUpdate` 直接透传 `req.body`，`wakeWords` 自动入库（无需改）。

### 管理台
- `admin/src/pages/AiAssistantPage.jsx`：新增「语音唤醒词」卡（`Input.TextArea`，逗号/换行分隔多词），`load()` 回填、`handleSave()` 提交（服务端负责拆分）。

### 前端 App
- 新增 `core/voice_wake.dart`（`VoiceWakeState extends ChangeNotifier`）：`enabled` 本地 pref（默认关）+ `wakeWords` 启动从后端拉（失败回落默认）；`main.dart` 的 `MultiProvider` 注册、随启动 `init()`。
- 新增设置页 `pages/profile/settings/wake_word_page.dart`（路由 `/profile/settings/wake`，`router.dart` 注册）：介绍 + 当前唤醒词 + 启用开关；`settings_home_page.dart`「通知与通用」加入口行。
- `widgets/voice_assistant_layer.dart`：
  - **可拖动靠边小球**：尺寸 54→46、默认偏下（纵向比例 0.82）、贴右；`onPanStart/Update/End` 拖动，松手按中线吸最近左/右边并 `AnimatedPositioned` 回弹；位置存 `SharedPreferences`（`voice_orb_side` + `voice_orb_top_frac`，按比例适配屏高），跨页面/重启还原。
  - **唤醒常听（全局）**：本层挂在 `ShellRoute` 上、覆盖所有登录后业务页，故常听不再限定一级 tab——`!_active && !kIsWeb && wakeEnabled && !MicCoordinator.busy` 即监听，二级页（搜索/详情/设置…）同样可「呼叫唤起」。识别文本模糊匹配（归一化包含 + 近音字 ≥0.75 重叠容错）命中唤醒词 → 停常听 → 进入正式聆听。`_activate` 前一律 `_stopWakeListening`、`_deactivate` 后按开关恢复。
  - **麦克风协调**：新增 `core/mic_coordinator.dart`（`MicCoordinator.busy` ValueNotifier）。唤醒常听与各页「语音输入」弹层共用同一 `OfflineStt` 单例，不能同时占麦；`VoiceInput.listen` 期间 `acquire()`（弹层前等一帧让唤醒停麦）、结束 `release()`，唤醒常听监听该标志自动让路/恢复。

## 契约

- `GET /ai/assistant/config`（需登录）→ `{ code:200, data:{ enabled:boolean, wakeWords:string[] } }`。
- `PUT /admin/ai-assistant/config` 接受 `wakeWords`（字符串或数组）。

## 验收

- 后端：`node --check` 三文件通过；`GET /ai/assistant/config` 仅回 `{enabled, wakeWords}`。
- 前端：`flutter analyze` 干净；web 浏览器实测小球变小/偏下/拖动吸边/位置持久化、设置页「语音唤醒」开关与唤醒词展示。
- ⚠️ **唤醒词真识别（说「你好小田」唤起）仅 APK 真机可用**（sherpa=ffi）；前端改动**必须重打 APK**才能在设备验证常听。

## 不在范围

- 唤醒词专用声学 KWS 模型 / 自定义训练（仍走通用 sherpa STT + 文本匹配）。
- Web 端真唤醒、多语言唤醒词。

## 实施备注

- 唤醒默认关（持续占麦/隐私/耗电），用户需到「设置 - 语音唤醒」手动开启。
- `offline_stt_io.dart` 增补麦克风诊断日志（`hasPermission` / 帧数 / 最大振幅 / partial），用于在模拟器上区分「麦克风喂静音」与「sherpa 识别侧问题」。

## 后续增补（2026-06-22）：有声无字自动结束

- 漏提交补齐：`core/mic_coordinator.dart`（麦克风占用协调器，上批 commit 遗漏未跟踪）随本批入库；语音图标素材 `assets/voice_icons/` 按设计素材策略写入 `.gitignore` 不入库。
- **「检测到噪音且 1 秒内没识别到文字 → 自动 end」**：`OfflineStt.start` 新增可选回调 `onNoSpeech`。
  - 触发条件：单帧归一化最大振幅 `> 0.02`（有声音活动）且当前完整文本仍为空，开一个 1 秒窗口；到点仍无字则触发一次 `onNoSpeech`。一旦出过字（`_sawSpeech`）即本轮永久关闭该机制，正常说话不受影响。
  - 接入：语音助手**正式聆听** → `_deactivate()`（结束聆听，不空等转圈）；各页**语音输入弹层** → `_cancel()`（自动收起）。
  - **唤醒常听不接** `onNoSpeech`（默认 null 即停用），否则环境噪音会不停打断后台监听。
  - web stub 同步签名（`onNoSpeech` 可选参），保持条件导出一致。
- 验收：`flutter analyze` 改动 5 文件 0 issue。真机噪音环境自动结束待 APK 复验。
