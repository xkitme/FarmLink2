# 分段 88 — 「我的」页「我的事务」区按参考图改不规则三栏

> 用户提供一张「我的」页参考图，要求按图重排。核对后确认：上半部分（hero / 4 项数据 / 订单·发布双入口卡 / 数据同步卡）与现状（分段 82）已基本一致，**真正差异只在底部「我的事务」区**。本段只动 `profile_page.dart` 的「我的事务」版式，数据来源 / 同步逻辑 / 路由 / 后端均不变。

## 一、目标

- 把「我的事务」从**规整 4 列 × 2 行图标宫格**改为参考图的**不规则三栏**：
  - 左栏竖排 4 项：农事记录 / 灾情记录 / 消息通知 / 农机服务（图标在左、文字在右的扁平描边小卡）。
  - 中栏两个大块：政策申请（白底）、适老模式（**绿底强调** + 「新」角标），图标+文字居中。
  - 右栏竖排 2 项：数据看板 / 设置（同左栏样式，顶对齐、下方留空）。
- 沿用 InkFlow 既有设计语言：主绿 token、方角 `R.sm/R.md`、扁平描边盒，对齐用户「利落方正」偏好，无新增色值。

## 二、背景

分段 82 已把「我的」页整体重排为「绿渐变 hero → 叠压概览卡 → 双入口卡 → 数据同步卡 → 4 列宫格」。本次用户参考图的上半部分与该版几乎一致，唯独「我的事务」区从对称宫格变成了更有层次的不规则三栏（中栏两块更大、适老模式绿底强调）。开工前已就「改动范围 / 三栏版式 / 入口卡图标」三点向用户确认（用户拍板：整页按参考图、三栏版式正确、入口卡图标保持现状不改 ⇄）。

## 三、改动

文件：`app/lib/pages/profile/profile_page.dart`

- 删除旧 `_taskGrid`（`GridView.count` 4 列）与 `_taskCell`。
- 新增 `_taskZone`：`IntrinsicHeight` + `Row(crossAxisAlignment: stretch)` 三栏：
  - 左 / 右栏用 `_taskList` → 多张 `_taskRowCard`（描边小卡：`Icon` size 20 + 文字，`InkWell` 跳路由）竖排堆叠、`mainAxisSize.min` 顶对齐。
  - 中栏 `Column` 内两个 `Expanded(_taskTile)` 等分填充左栏总高；`_taskTile` 支持 `highlight`（绿底=`primaryContainer` α0.14 + α0.35 描边 + 主绿图标文字）与 `badge`（右上「新」角标）。
- `_TaskItem` 去掉不再使用的 `badge` 字段。
- `build()` 中 `_taskGrid(context)` 调用改为 `_taskZone(context)`；其余（hero / 概览 / 双入口卡 / `_syncPanel`）一字未动。

实现要点：

- 用 `IntrinsicHeight`（内容驱动高度）而非固定高度，避免适老模式 1.3× 全局字号下溢出。
- 横向 `stretch` 让中栏两块按左栏 4 行的总高等分；右栏 2 项自然顶对齐、下方为透明背景（非空卡），与参考图右侧「设置下方留白」一致。
- 颜色仅用既有 token（`primary` / `primaryContainer` / `surface` / `outlineVariant` / `onSurface` / `error`），无新增色值、无新组件。
