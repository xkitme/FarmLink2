## 本次任务目标

在比赛环境可能完全断网的前提下，补齐后端本地 AI 能力：

- 接入 Ollama 本地模型，不依赖云端 API。
- 使用 SQLite 里的政策、农技、应急、生活服务数据做本地 RAG。
- Ollama 未启动或模型不可用时，自动降级到本地规则/RAG，保证接口不废。
- 提供 AI 状态、模型版本、在线调试、问答记录、语音识别适配、图像识别入口。
- 将原 `policy` 模块的政策问答/法律问答升级到统一 AI 编排。

## 执行内容

### 1. Ollama 本地模型服务

新增 `backend/src/modules/ai/services/ollama.service.js`：

- `GET /api/tags` 检测 Ollama 是否在线。
- `/api/generate` 支持非流式文本生成。
- `/api/generate` 支持 JSONL 流式生成，并转成后端 SSE。
- 支持 vision 模型传入 base64 图片。
- 不新增外部 npm 依赖，直接使用 Node.js 内置 `fetch`。

默认模型配置调整：

```text
OLLAMA_PRIMARY_MODEL=qwen2.5:1.5b-instruct-q4_K_M
OLLAMA_VISION_MODEL=minicpm-v:8b-2.6-q4_K_M
OLLAMA_EMBED_MODEL=bge-m3
```

说明：1.5B Q4 默认更适合 RTX 5060 Laptop 8GB 的比赛演示。实际机器有余量时，可在 `.env` 中改成 3B 或 7B。

### 2. SQLite 本地 RAG

新增 `backend/src/modules/ai/services/rag.service.js`：

- `POLICY`：检索 `PolicyChunk` 和政策元数据。
- `AGRI`：检索病害知识、农药信息、农事日历。
- `DISASTER`：检索应急预案。
- `LIFE/EDU/LOAN`：检索岗位、贷款、培训课程。
- `GENERAL`：跨政策、农技、应急、生活服务做轻量聚合检索。

检索策略采用本地关键词/ngram 打分，不依赖 Milvus、Elasticsearch 或联网 embedding，因此比赛断网可用。

### 3. AI 问答编排

新增 `backend/src/modules/ai/services/ask.service.js`：

```text
用户问题
  → SQLite 本地 RAG 检索
  → 拼装 Prompt
  → 优先调用 Ollama 本地模型
  → 失败时降级 local-rule-rag
  → 写入 t_ai_qa_record
```

新增 `backend/src/modules/ai/services/fallback.service.js`：

- 场景化 system prompt。
- 政策/农技/法律/灾害/生活场景规则兜底。
- 法律场景内置土地流转、欠薪、农资纠纷、征地补偿等常见问题方向性建议。

### 4. SSE 流式问答

`POST /api/v1/ai/chat` 支持：

```json
{
  "scene": "POLICY",
  "question": "我能申请农机补贴吗？",
  "stream": true
}
```

如果 Ollama 在线，后端以 SSE 推送模型输出；如果 Ollama 不在线，则把本地规则/RAG 答案拆段推送，仍保证前端流式体验可演示。

### 5. 语音识别适配接口

`POST /api/v1/ai/voice/recognize` 支持：

- 上传音频文件字段 `audio`。
- 或直接传 `text/transcript` 做比赛演示。

当前实现为离线语音适配层：

- 后端记录语音识别结果到 `t_ai_qa_record`。
- 根据识别文本粗分意图：政策问答、农技问答、灾害求助、通用对话。
- 后续接入 Flutter 端 whisper.cpp 或本机 whisper 服务时，只需要替换 transcript 来源。

### 6. 图像识别统一入口

`POST /api/v1/ai/image/analyze` 支持图片字段 `image` 和参数：

```text
detectType=DISEASE/GRADE/SEED/GROWTH
cropType=水稻
productName=苹果
```

执行策略：

- Ollama vision 模型可用时，传入 base64 图片进行本地视觉分析。
- 不可用时，使用本地规则/知识库兜底。
- 识别结果写入 `t_ai_detect_record`。

## 比赛部署提示

比赛前建议在有网环境提前下载模型：

```bash
ollama pull qwen2.5:1.5b-instruct-q4_K_M
ollama pull bge-m3
```

图像识别如果要展示视觉模型增强，可提前准备：

```bash
ollama pull minicpm-v:8b-2.6-q4_K_M
```

现场断网时只需要：

```bash
ollama serve
npm run dev:backend
```

即使 Ollama 未启动，AI 接口仍会走 SQLite RAG + 本地规则兜底，保证演示不断。
