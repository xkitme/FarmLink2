## #2 · 购物车库存上限（clamp）

- `app/lib/pages/market/market_page.dart`：
  - `_Product` 增 `int stock`（const 默认 99；`_Product.fromApi` 解析 `(json['stock'] as num?)?.toInt() ?? 0`）。列表接口 `GET /market/product/list` 经 `shape(p)` 返回原始行含 `stock`。
  - `_addCart`：`stock > 0 && 当前数量 >= stock` 时 toast「库存仅 N {unit}」并不再 +1。
  - `_showProductDetail` 详情页数量回传合并：`min(已有+回传, stock)` 夹住上限。
  - 购物车清单 sheet（`_showCart`）只有「移除」、无 +/- stepper，无新增入口，故无需额外 clamp。
- 边界：`stock <= 0`（接口未返回/解析失败）视为未知，**不拦截**，避免误把可售商品锁死；`_checkout` 下单语义不变（按已夹住的数量逐项提交）。

## #3 · 产地名称（不露裸地区码）

- `app/lib/core/constants.dart`：新增 `kRegionNames`（六个 seed 实际用到的码：510000 四川省 / 510100 成都市 / 510131 蒲江县 / 510131100 寿安街道 / 510131100201 松华村 / 510131100202 长滩村）+ `String regionName(String? code)`，未知/空回退「乡村产地」，**永不展示裸数字码**。
- `app/lib/pages/market/product_detail_page.dart` `_origin`：优先 `seller.villageName`，否则 `regionName(_regionCode)`，再否则「乡村产地」。seed 商品 `regionCode = 510131100201` → 松华村。
