# 分段 45k — 主页「今日最重要的事」决策卡（视觉记忆点 D2）

> 工作单（Codex 实施）。所属 lane：[45-招牌场景与产品重构计划](45-招牌场景与产品重构计划.md) Lane D · D2。
> 进入首页第一眼就看到「平台在帮我做决定」。**复用现有接口，新增一次农事待办查询。**

## 一、目标

主页最顶（气象 strip 之上）加一张**今日决策卡**：按优先级算出「今天最重要的一件事」+ 一个大 CTA 直达处理。让首页从「功能入口堆」变成「平台主动给我建议」。

## 二、决策优先级（从高到低，命中即停）

| 优先级 | 条件 | 卡片文案 | CTA → |
|---|---|---|---|
| P1 | 有气象红色/橙色预警（weather.alerts 非空） | ⚠「{alertLevel}：{title}」 | 查看防护 → `/disaster` |
| P2 | 今日有到期农事待办（recordDate ≤ 今天 且 recordType ∈ 复查/打药/施肥…，未完成） | 🌱「今日农事：{content}」 | 去处理 → `/agri` |
| P3 | 未来 3 天有农事待办 | 📅「{n} 天后：{content}」 | 查看日历 → `/agri` |
| P4 | 待发送队列 > 0 | 🔄「{n} 条数据待同步」 | 立即同步 → `/data/service` |
| P5 | 未读消息 > 0 | ✉「{n} 条新消息」 | 查看 → `/messages` |
| P6 | 兜底（无事项） | ☀「今日天气{condition}，适宜农事」 | 看农情 → `/data` |

## 三、改动清单

### 1. `app/lib/pages/home/home_page.dart`

#### 3.1 `_load` 增加农事待办查询

现有 `_load` 已并行拉 weather / notification / life-help / queue（44a）。再加一项：

```dart
ApiClient.get('/agri/record/list', query: {'pageNum': 1, 'pageSize': 20}),
```

解析出「未来 7 天内 + 今天」的待办记录（recordDate 在 [今天, 今天+7天]，recordType 含「复查/打药/施肥/灌溉/采收」），存 `_todoRecords`。
单接口失败不阻塞（try/catch 包，失败则 `_todoRecords = []`）。

#### 3.2 决策计算

```dart
_Decision _computeDecision() {
  // P1 预警
  if (_alerts.isNotEmpty) {
    final a = _alerts.first;
    return _Decision(
      icon: Icons.warning_amber_rounded,
      tone: AppColors.error,
      title: '【${a['alertLevel'] ?? '预警'}】${a['title'] ?? a['content'] ?? '请注意防范'}',
      cta: '查看防护', route: '/disaster',
    );
  }
  // P2 今日到期农事
  final today = DateTime.now();
  final todayItem = _todoRecords.firstWhereOrNull((r) {
    final d = DateTime.tryParse('${r['recordDate'] ?? ''}');
    return d != null && !d.isAfter(DateTime(today.year, today.month, today.day, 23, 59));
  });
  if (todayItem != null) {
    return _Decision(
      icon: Icons.eco_rounded, tone: AppColors.primary,
      title: '今日农事：${todayItem['content'] ?? todayItem['recordType']}',
      cta: '去处理', route: '/agri',
    );
  }
  // P3 未来 3 天
  final soon = _todoRecords.firstWhereOrNull((r) {
    final d = DateTime.tryParse('${r['recordDate'] ?? ''}');
    if (d == null) return false;
    final diff = d.difference(today).inDays;
    return diff >= 0 && diff <= 3;
  });
  if (soon != null) {
    final d = DateTime.tryParse('${soon['recordDate']}')!;
    final days = d.difference(today).inDays;
    return _Decision(
      icon: Icons.event_note_rounded, tone: AppColors.primaryContainer,
      title: '$days 天后：${soon['content'] ?? soon['recordType']}',
      cta: '查看日历', route: '/agri',
    );
  }
  // P4 待发送
  if (_waiting > 0) {
    return _Decision(icon: Icons.sync_alt_rounded, tone: AppColors.warning,
      title: '$_waiting 条数据待同步', cta: '立即同步', route: '/data/service');
  }
  // P5 未读
  if (_unread > 0) {
    return _Decision(icon: Icons.mail_rounded, tone: AppColors.primary,
      title: '$_unread 条新消息', cta: '查看', route: '/messages');
  }
  // P6 兜底
  final cond = '${_today['condition'] ?? '晴'}';
  return _Decision(icon: Icons.wb_sunny_rounded, tone: AppColors.primary,
    title: '今日天气$cond，适宜农事', cta: '看农情', route: '/data');
}
```

> `firstWhereOrNull` 用 `package:collection` 或自己写个扩展（项目里 market_page 已有 `_FirstOrNull` 扩展，可复用模式）。

Widget _decisionCard() {

    child: Material(
      color: Colors.transparent,

          padding: const EdgeInsets.all(18),

              width: 48, height: 48,

## 四、验收

1. `flutter analyze lib/pages/home` → No issues
2. 制造各优先级场景，决策卡正确切换：
   - 有预警 → 红卡「暴雨预警」→ 点击跳 /disaster
   - 无预警 + 今日有「复查」农事 → 绿卡「今日农事：XX复查」→ 跳 /agri
   - 都没有 + 有待发送 → 橙卡「N 条待同步」→ 跳 /data/service
   - 全空 → 兜底「今日天气晴，适宜农事」
3. **与 45b 联动验证**：用 45b 拍照建档（7 天后复查），手动把该 record 的 recordDate 改成今天 → 首页决策卡显示「今日农事：黑星病复查」
4. 决策卡点击跳对应路由
5. `/agri/record/list` 失败 → 决策卡降级到 P4/P5/P6，不崩
