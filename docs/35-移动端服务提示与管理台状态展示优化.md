# 分段 35 — 移动端服务提示与管理台状态展示优化

## 本次目标

继续推进 Flutter App 后续板块体验优化与联调，重点处理用户可见的技术异常提示、服务状态图标和管理台英文枚举展示，保证移动端与管理面板都保持正式成品口径。

## 问题定位

1. 移动端多个交互动作在失败时直接拼接 `$e` 或 `error`，可能把接口异常、超时、技术细节展示给用户。
2. 部分页面仍有“后端暂不可用”一类开发视角文案。
3. 通用错误组件和数据管理提示使用 `cloud_off` 图标，视觉上容易暗示断网或离线。
4. 管理台业务 CRUD 表格、详情和下拉框直接展示 `PENDING / SUBMITTED / REPORTED` 等英文枚举，成品感不足。

## 已完成内容

1. `app/lib/widgets/common.dart`
   - 新增 `serviceUnavailableMessage`、`serviceErrorMessage`、`actionErrorMessage`。
   - `ApiException` 中的后端中文业务原因会保留；网络、超时和技术异常统一收口为“服务暂时不可用，请稍后重试”。
   - `ErrorRetry` 图标由 `cloud_off` 改为 `error_outline_rounded`。
2. Flutter 登录注册与服务页
   - 登录、注册失败提示改为正式服务口径，避免直接展示异常对象。
   - 数据看板、个人中心、消息、数据管理服务页的错误状态和 Toast 改为统一 helper。
3. Flutter 八大业务板块交互动作
   - 农业生产、AI、灾害、政策、农机、流通销售、乡村生活等页面的失败 Toast 不再拼接原始异常。
   - 集市和农机主页面移除“后端暂不可用，已展示内置数据”文案，改为统一服务提示。
   - 数据管理服务页提示图标由 `cloud_off` 改为信息提示图标。
4. `backend/admin/src/pages/ResourcePage.jsx`
   - 管理台资源表格新增角色、状态、操作枚举中文映射。
   - 列表、详情抽屉和表单 Select 下拉项均显示中文标签。
   - 数字状态字段统一显示“启用 / 停用”标签。
