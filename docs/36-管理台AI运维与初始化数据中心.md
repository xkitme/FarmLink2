# 分段 36 — 管理台 AI 运维与初始化数据中心

## 本次目标

继续补齐管理台“功能丰富”的交付要求，在已有业务 CRUD、API 开关、在线调试和操作日志基础上，新增 AI 运维中心与初始化数据中心，让后台具备更完整的运行状态查看、模型配置查看、知识库检索和数据覆盖检查能力。

## 问题定位

1. 管理台侧边栏中的 AI 能力区域主要指向 AI 记录 CRUD，缺少专门的 AI 服务状态与配置视图。
2. 初始化数据、资源覆盖情况和种子脚本位置没有集中入口，维护时需要人工翻文件。
3. API 在线调试模板里仍有少量技术存储口径文案，不符合产品呈现口径。
4. 后台顶部存在 `SQLite 数据服务` 标签，用户可见层面不应强调底层数据库实现。

## 已完成内容

1. 后端新增 `GET /api/v1/admin/seed/summary`
   - 汇总 9 个资源分组、36 个后台资源项的数据记录数量。
   - 返回 API 开关数量、操作日志数量、初始化脚本、数据结构文件和常用维护命令。
   - 只提供概览与命令复制信息，不提供危险的一键重置动作。
2. 新增管理台 `AI 运维中心`
   - 展示 AI 服务状态、问答记录数、识别记录数、知识切片数和 AI 开关数量。
   - 展示问答模型、视觉模型、检索模型配置。
   - 展示已识别模型列表。
   - 提供知识库检索调试入口。
   - 展示最近 AI 问答记录与 AI 功能开关。
3. 新增管理台 `初始化数据中心`
   - 展示业务板块、资源配置、数据记录和 API 开关概览。
   - 展示各板块数据覆盖情况和每个资源的记录数。
   - 支持复制依赖安装、结构同步、初始化和启动命令。
   - 展示初始化脚本、数据结构文件、数据文件等维护信息。
4. 管理台路由与菜单调整
   - 新增 `/ai-ops`、`/seed-data` 页面。
   - AI 菜单拆分为“AI 运维中心”和“AI 记录”。
   - 系统治理新增“初始化数据”入口。
   - 顶部标签改为“平台数据服务”。
5. API 调试模板口径回扫
   - 去除用户可见的底层数据库口径描述。
   - 增加 AI 模型配置与初始化数据概览接口模板。
