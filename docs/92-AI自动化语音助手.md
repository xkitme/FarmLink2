# 分段 92 — AI 自动化语音助手（P0/P1/P2 分批开发）

> 新功能：在现有 AI 农技体系内加入语音自动化助手。入口放在 `/ai` 页面与一级 Tab 悬浮小球；激活后覆盖当前页面，提供语音识别、多轮回复、TTS 播报和白名单自动化指令。

## 一、分 P 计划

### P0：助手骨架与安全协议（本轮）

- `/ai` 页面新增“AI 语音助手”主入口。
- `ShellPage` 仅在五个一级 Tab 页面叠加轻量悬浮助手球。
- 激活态覆盖当前页面：大号渐变语音球、全屏边缘渐变灯带、底部回复气泡、可退出。
- 前端新增非弹窗式语音识别控制：3 秒静默自动提交；点击大球立即提交当前识别文本。
- 后端新增 `/api/v1/ai/assistant/turn` 与 `/api/v1/ai/assistant/command-result`。
- 后端输出固定 command schema，并做白名单校验；前端只执行白名单命令。
- DeepSeek 配置与调用骨架：`DEEPSEEK_API_KEY` / `DEEPSEEK_BASE_URL` / `DEEPSEEK_MODEL`；缺失或失败走 Ollama JSON 兜底。
- 抽出共享 Markdown 渲染组件，聊天页和助手回复气泡共用。

### P1：业务闭环

- 新增订单页 `/market/orders`，支持 `dingdan` / `订单` / `orders` 语义映射。
- `User` 增加 `shippingAddress`，资料编辑页新增“收货地址”。
- 订单确认读取 `realName` / `phone` / `shippingAddress`；地址为空时先引导补全。
- 新增 mock 支付接口或收紧现有状态更新路径，仅允许买家 `PENDING -> PAID`。
- 种子数据补“环保编织手链”“乡村文创玩偶”等演示商品。

### P2：体验打磨与真机验收

- 连续多轮语音与 TTS 同时工作时做回声/误触防护。
- 指令执行状态条细化为“正在打开订单 / 正在确认地址 / 支付已完成”等。
- 覆盖 APK 真机麦克风权限、浏览器语音不可用降级、长回复 TTS 播报。
- 完整 demo：推荐手链/玩偶 -> 选择手链 -> 打开商品 -> 地址确认 -> 创建订单 -> mock 支付 -> 成功播报 -> “没有了”关闭。

## 二、接口契约

### POST `/api/v1/ai/assistant/turn`

请求：

```json
{
  "text": "帮我推荐一个手链",
  "route": "/ai",
  "context": {
    "lastReply": "可选，前端保留的上一轮回复"
  }
}
```

响应：

```json
{
  "replyMarkdown": "我先帮你找几个适合的乡村好物。",
  "speakText": "我先帮你找几个适合的乡村好物。",
  "commands": [
    { "type": "open_page", "params": { "routeKey": "market" } }
  ],
  "statusText": "正在打开集市",
  "modelUsed": "deepseek-chat",
  "serviceMode": "AI语音助手"
}
```

### POST `/api/v1/ai/assistant/command-result`

请求：

```json
{
  "text": "open_page 执行完成",
  "route": "/market",
  "result": {
    "command": "open_page",
    "ok": true
  }
}
```

响应同 `assistant/turn`，用于命令执行后让后端决定下一步。

## 三、Command Schema

只允许这些命令：

- `open_page { routeKey }`
- `show_products { productIds }`
- `open_product { productId }`
- `show_order_confirm { productId, quantity }`
- `create_order { productId, quantity, receiverInfo }`
- `mock_pay { orderId }`
- `show_message { markdown, speak }`
- `end {}`
