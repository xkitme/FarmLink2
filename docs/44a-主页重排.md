```dart
Widget _weatherStripCard() {
  final t = _today;
  final cond = '${t['condition'] ?? '晴'}';
  final low = _int(t['tempLow']);
  final high = _int(t['tempHigh']);
  final humidity = _int(t['humidity']);
  final wind = _int(t['windLevel']);
  // soil status 用 _soilStatusOf(humidity, cond) 这个 helper（从原 _soilCard 抽出来）
  return AppCard(
    onTap: () => context.go('/disaster'),
    child: Row(
      children: [
        Icon(_conditionIcon(cond), color: AppColors.primary, size: 32),
        const SizedBox(width: 12),
        Column(
          crossAxisAlignment: CrossAxisAlignment.start,
          children: [
            Text('$low°~$high°  $cond',
                style: ... fontSize 16, w700),
            Text('湿度 $humidity% · 风 $wind 级 · 墒情$soilStatus',
                style: ... fontSize 12, onSurfaceVariant),
          ],
        ),
        const Spacer(),
        const Icon(Icons.chevron_right, color: AppColors.outline),
      ],
    ),
  );
}
```

#### 4.4 新增 `_quickPanel()` 我的快讯三联卡

数据来源：

- 未读消息 → `NotificationState.unread`（已有 ValueNotifier）+ 最近一条 title
  → 需要在 `_load` 内拉一次 `/notification/list?pageNum=1&pageSize=1` 取第一条
- 待发送 → `OfflineSyncQueue.waitingCount()` + 最近一条 tableName
  → `_load` 内拉一次 `OfflineSyncQueue.all()`，filter status != synced
- 最近发布 → `/life/help/list?pageNum=1&pageSize=1`（互助求助）
  字段：title、createdAt；若调用失败显示「暂无发布」

```dart
Widget _quickPanel() {
  return Row(
    children: [
      Expanded(child: _quickCard(
        icon: Icons.mail_rounded,
        color: AppColors.primary,
        title: '未读消息',
        accent: '$_unread',
        subtitle: _latestNotification?.title ?? '暂无新消息',
        onTap: () => context.go('/messages'),
      )),
      const SizedBox(width: 8),
      Expanded(child: _quickCard(
        icon: Icons.sync_alt_rounded,
        color: _waiting > 0 ? AppColors.warning : AppColors.primary,
        title: '待发送',
        accent: '$_waiting',
        subtitle: _lastErr ?? '数据已同步',
        onTap: () => context.go('/data/service'),
      )),
      const SizedBox(width: 8),
      Expanded(child: _quickCard(
        icon: Icons.add_circle_outline,
        color: AppColors.secondary,
        title: '最近发布',
        accent: _latestPublish == null ? '—' : '·',
        subtitle: _latestPublish?.title ?? '暂无发布',
        onTap: () => context.go('/publish'),
      )),
    ],
  );
}

Widget _quickCard({
  required IconData icon,
  required Color color,
  required String title,
  required String accent,
  required String subtitle,
  required VoidCallback onTap,
}) {
  return AppCard(
    padding: const EdgeInsets.symmetric(horizontal: 10, vertical: 12),
    onTap: onTap,
    child: Column(
      crossAxisAlignment: CrossAxisAlignment.start,
      children: [
        Row(children: [
          Icon(icon, color: color, size: 16),
          const SizedBox(width: 4),
          Text(title, style: TextStyle(fontSize: 12, color: AppColors.onSurfaceVariant)),
          const Spacer(),
          if (accent != '—' && accent != '·')
            Text(accent, style: TextStyle(fontSize: 14, fontWeight: FontWeight.w700, color: color)),
        ]),
        const SizedBox(height: 8),
        Text(subtitle, maxLines: 2, overflow: TextOverflow.ellipsis,
            style: const TextStyle(fontSize: 12, height: 1.35,
                color: AppColors.onSurface)),
      ],
    ),
  );
}
```

#### 4.5 `_load` 扩展

现状只调用 `/agri/weather`。改成并行：

```dart
final results = await Future.wait<dynamic>([
  ApiClient.get('/agri/weather'),                           // 0
  ApiClient.get('/notification/list', query: {'pageNum': 1, 'pageSize': 1}), // 1
  ApiClient.get('/life/help/list', query: {'pageNum': 1, 'pageSize': 1}),    // 2
  OfflineSyncQueue.all(),                                   // 3
]);
```

字段提取：
- weather: 同现状 `days` / `alerts`
- notification: `records[0]` → `_latestNotification = { title, type, createdAt }`，
  同时 `unreadCount` 或不用（hero 不再显示数字，由 NotificationState 的 ValueNotifier 提供）
- 实际 unread 数：直接 `context.watch<...>(NotificationState.unread)`，但 NotificationState 是 static —— 在 build 顶部用 `ValueListenableBuilder` 包 _quickPanel，或者改成 setState 监听
  - **建议简化**：在 _load 内也调用一次 `NotificationState.refresh()`，然后用 `_unread = NotificationState.unread.value`，listen 由外层 ShellPage 负责（如果离开页面切回，会自动 refresh）
- life/help：`records[0]` → `_latestPublish = { title, createdAt }`
- queue: `_waiting = queue.where(status != synced).length`，`_lastErr = queue.firstWhereOrNull(...).lastError`

任意单接口失败不阻塞整体：用 try/catch 包每一个 `await`，失败时该字段保持 null，对应 quickCard 显示「暂无 ...」。
