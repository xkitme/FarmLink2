## 一、目标

`app/lib/pages/data/data_dashboard_page.dart` 的 `_cropAreaCard()`（约 492 行，现在用 `_barRow` 画水平柱条）升级为：
- 左侧/上方一个**手绘环形图**（donut），按各作物 `areaMu` 占比分扇区
- 右侧/下方**图例**：色块 + 作物名 + 面积 + 百分比
- 中心可留空或写总面积「N 亩」

## 二、改动清单（单文件，纯前端）

### 1. 新建私有 `CustomPainter` 画环形图

在 `data_dashboard_page.dart` 内（文件底部）加一个 `_DonutPainter extends CustomPainter`：
- 入参：`List<({double value, Color color})> slices`、`strokeWidth`
- 用 `Canvas.drawArc`（`useCenter: false` + `Paint..style=PaintingStyle.stroke..strokeWidth=...`）逐段画弧，按 value 占比算每段 `sweepAngle`（总和 2π），起点 `-π/2`（12 点方向）
- 段之间可留 ~2° 细缝（可选），总占比为 0 时不画（交给外层兜底）
- `shouldRepaint` 比较 slices 变化即可（简单返回 true 也可接受）

> 用稳妥通用 API（`drawArc`/`Paint`/`Path`），别用版本敏感的新绘图 API（比赛机 Flutter 3.44）。

### 2. 改 `_cropAreaCard()`

- 取 `cropArea` 列表（现有 `_list(_dashboard['cropArea'])`），每项 `{cropType, areaMu}`。
- 计算总面积 `total = Σ areaMu`；各扇区颜色复用现有 `_cropColor(cropType)`。
- 空列表 → 保持现有「暂无地块面积数据」兜底文案不变。
- 非空 → 渲染：
  - 环形图：`SizedBox(width/height ~120-140)` + `CustomPaint(painter: _DonutPainter(slices))`，中心 `Text('${_num(total)}\n亩')` 居中（小字）。
  - 图例：`Column` 每行 `Row[ 10x10 圆点(_cropColor) , 作物名(Expanded,省略) , '${_num(areaMu)}亩 · {pct}%' ]`，`pct = total==0?0:(areaMu/total*100).round()`。
  - 取前 6 项，多余的并成「其他」一项（可选，超过 6 类时再做；≤6 不必）。
- 用 `Row`（窄屏可 `Wrap` 或上下排）布局，**不溢出**。
- **保留 `_barRow` 方法不删**（其它地方可能复用；本卡不再调用它即可，避免误删引发 analyze 报未使用——若 analyze 报 `_barRow` unused，则确认全文件确实没人用后再删，或保留被调用处）。

### 3. 视觉（Agro-Modernist，审美在线）

- 扇区/图例色用现有 `_cropColor`（主绿/麦金/大地棕系），背景白卡 `AppCard`。
- **禁** generic 渐变 / 半透明白浮层 / 脉冲光 / 大圆角胶囊。环形描边粗细适中（如 16-20）、首尾留细缝即可，不要花哨。
