## 1. 目标

在 116h-A shell 初版（五栏底栏 / FarmBrand / 设计 token / 统一五态 / 适老可见化）基础上，
只打磨 Flutter 壳层质量，不迁移业务页面：

1. **适老底栏密度**：修复「小田助手」在 411 窄屏折行成两行导致的底栏偏挤 / 跨宽度高度跳动；
2. **AppBootstrap / ElderModeState 三路径核验**：启动读偏好、profile 默认、切换持久化一致，
   补充 headless web 注入口径注释与测试；
3. **FarmBrand 统一落点**：splash 旧「叶子图标 + 田园通」胶囊、FarmAppBar 旧叶 icon 统一为品牌图；
4. **首页信息架构**：保持 首页/集市/发布/小田助手/我的 五栏，铃铛顶栏，不恢复「消息」底栏；
5. **五态落地**：首页 2 个使用点（整页加载态 FarmLoading、空行情 FarmEmpty compact），
   设计系统新增 compact 空态与品牌兜底组件；
6. **响应式壳层**：Web 手机框 / 移动端全宽 / 底部 SafeArea / VoiceAssistantLayer 覆盖层截图验收；
7. **视觉资产**：全程使用真实 `assets/images/farmlink-mark.png`，不用通用图标替身；
8. **测试补强**：适老 nav 机制、AppBootstrap/ElderMode 三路径、FarmBrand fallback、五态全分发。

## 3. 接口契约（本批新增/变更）

- `FarmShellNavBar({selectedIndex, elder, onSelect})`：公开底栏组件；`kShellTabs` 契约不变
  （`['/home','/market','/publish','/ai','/profile']`，标签 首页/集市/发布/小田助手/我的）。
- `FarmEmpty(text, {icon, compact})`：`compact=true` 时渲染 20px 图标 + 13px 文案的行内空态，
  默认整页居中模式不变。
- `FarmBrandMarkFallback({markSize})`：品牌图加载失败的主绿圆角方块兜底。
- `ElderModeState` 三路径契约（§1.2）：本地偏好 > profile 默认（立即持久化）> 默认关；
  web 注入布尔值写 JSON 字面量 `'true'/'false'`。
