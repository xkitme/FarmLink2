# 分段 47a — 后端启动乱码修复（GitHub issue #1）

> 工作单（Codex 实施）。所属批次：[47-GitHub-issues处理](47-GitHub-issues处理.md)。
> 解决 GitHub issue #1「启动后端时，命令行出现乱码」（作者 yzk225）。
>
> 完成后关闭 issue #1。

## 一、现状（已确认）

- `start.bat` 顶部没有 `chcp 65001`，cmd / 旧 PowerShell 默认代码页 GBK (CP936)
- `scripts/start-local.ps1` 也没强制 Console UTF-8
- `backend/src/server.js` 启动日志含中文（`✓ SQLite 数据库已连接` / `🌾 FarmLink 田园通服务已启动` 等），且没有 stdout 编码兜底
- 中文用户在 cmd 启动看到 `锟斤拷` / `烫烫烫`

## 二、改动清单

### 1. `start.bat` —— 顶部加 chcp 65001

```bat
@echo off
chcp 65001 >nul
setlocal
cd /d "%~dp0"
echo Starting FarmLink local services...
powershell -NoProfile -ExecutionPolicy Bypass -File "%~dp0scripts\start-local.ps1" %*
if errorlevel 1 (
  echo FarmLink startup failed. Check .runtime logs for details.
  exit /b %errorlevel%
)
echo.
echo FarmLink local services are running.
echo Backend API:  http://localhost:8000/api/v1
echo Admin panel:  http://localhost:5173/admin/
echo Mobile web:   http://localhost:5000
echo Logs:         %~dp0.runtime
```

**关键**：`chcp 65001 >nul` 必须在 `@echo off` 之后、其它输出之前。`>nul` 把 `Active code page: 65001` 提示吞掉。

### 2. `scripts/start-local.ps1` —— 顶部强制 Console UTF-8

在脚本最开头（任何输出之前）加：

```powershell
# Force UTF-8 console output for Chinese log compatibility
[Console]::OutputEncoding = [System.Text.Encoding]::UTF8
$OutputEncoding = [System.Text.Encoding]::UTF8
chcp 65001 > $null
```

> Codex 注：`scripts/start-local.ps1` 行首如果有 `#Requires` / `param()` 块，UTF-8 设置应该放在它们之后、其它语句之前。

### 3. `backend/src/server.js` —— Node 端兜底

在 `import` 块之后、`bootstrap()` 之前加：

```js
// Windows 终端默认 GBK，强制 stdout/stderr UTF-8 以兼容中文日志
if (process.platform === 'win32') {
  try {
    process.stdout.setDefaultEncoding?.('utf8')
    process.stderr.setDefaultEncoding?.('utf8')
  } catch (_) {
    // 忽略，环境不支持就走默认
  }
}
```

> 这是双保险：即使用户没用 `start.bat` 直接 `node src/server.js`，Node 也会尽量按 UTF-8 写出。

### 4. `backend/admin/` 的启动脚本

`backend/admin` 是 Vite 项目，npm scripts 由 vite 启动。`vite` 默认按系统区域输出，但 vite 本身的英文日志不会乱。如果 vite 输出含中文（一般不会），同样原理需要 `chcp 65001`。

**本工作单不动 vite 配置**，只要外层 `start.bat` / `start-local.ps1` 已经 set codepage 即可继承。
