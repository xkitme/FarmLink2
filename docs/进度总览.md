## 技术约束（来自比赛需求）

- 强制离线部署，完整项目包可参赛
- 全部后端功能部署在本机
- 轻量数据库（SQLite）
- 不用 Docker
- AI 功能必须有，本地模型
- 管理面板功能丰富：数据增删改查、API 开关、API 在线调试

## 业务规模

- 8 大板块、**76 个功能模块**（要求全部能跑）
- 24 个 AI 融合模块
- 40+ 数据表
- 9 个后端业务包：agri / market / machinery / disaster / policy / life / data / ai / platform

## 重要约定

1. 统一响应格式：`{ code, msg, data, timestamp, traceId }`
2. 错误码：200 成功 / 40001 参数错 / 40101 未登录 / 40301 无权限 / 40401 不存在 / 42901 限流 / 50001 服务器错 / 60001 AI 繁忙 / 60002 离线降级
3. 角色：FARMER 农户 / BIGFARMER 大户 / VILLAGE 村委 / EXPERT 农技员 / MERCHANT 商家 / ADMIN 管理员
4. 所有业务表带 `local_uuid` 字段支持离线同步去重
5. 管理面板与移动端共用后端，管理面板走 `/admin` 路由
