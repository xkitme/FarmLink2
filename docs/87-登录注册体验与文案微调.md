# 分段 87 — 登录/忘记密码页体验修复 + 文案微调

> APK 上机后用户反馈的零散体验问题（虚拟机 Pixel 2，411×731 dp）与一处文案。

## 一、目标

让认证页在中等高度机型（Pixel 2，731dp）上一屏装下、去掉图片绿色蒙版，并改一处标签文案。

## 二、改动

### 1. 文案：个人资料「角色」→「身份」
- `app/lib/pages/profile/settings/account_page.dart`：`账号资料` 分组里 `_infoRow('角色', …)` 标签改为 `'身份'`。

### 2. 登录 / 忘记密码：去图片绿色蒙版
- 两个 hero 的渐变 `DecoratedBox` 原本掺绿，视觉上像给配图盖了层绿膜：
  - 登录：`[0x992A2E27, 0x00000000]`（深绿灰）
  - 忘记密码：`[0xAA2A2E27, 0x332E7D32]`（顶绿灰 + **底部品牌绿** `2E7D32`）
- 均改为**中性黑半透明**（仅压暗顶部供白色 logo / 返回箭头可读），去掉绿色：
  - 登录：`[0x73000000, 0x00000000]`
  - 忘记密码：`[0x80000000, 0x00000000]`

### 3. 忘记密码页一屏装不下 + 登录页可拖动
- 根因：`SingleChildScrollView + ConstrainedBox(minHeight: maxHeight)`——内容超一屏才会出现可拖滚动；忘记密码 4 个输入框 + compact hero 偏高，731dp 溢出。
- `forgot_password_page.dart`：compact hero `0.28→0.22`（clamp min `160→148`）、副标题间距 `24→16`、字段间距 `16→12`。
- `login_page.dart`：compact hero `0.34→0.30`（clamp min `190→180`），内容落一屏内、不再可拖。

## 三、验收

- `flutter analyze` 两页通过；`flutter build web` 成功。
- **411×731（Pixel 2 dp）网页实测**（登出态）：
  - 登录页：配图无绿蒙版；`欢迎回来 / 账号 / 密码 / 协议勾选 / 安全登录 / 注册账号` 全部一屏可见，底部按钮不被裁、无可拖溢出。
  - 忘记密码页：配图无绿蒙版；`重置密码 / 4 个输入框 / 重置密码 / 返回登录` 全部一屏可见。

## 四、不在范围内

- 配图本身（`auth-hero.jpg`）不替换，只调蒙版。
- 其它机型（更矮屏 <700dp）若仍紧，可再降 compact 比例，本段以 731 为准。

## 五、实施备注

- 用**网页版按 411×731 dp**验证（与虚拟机同尺寸、比模拟器盲点击可靠）。
