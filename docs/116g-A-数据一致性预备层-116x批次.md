## 1. 目标

为订单 / 数据同步 / 农机预约 / 平台资源四块建立「controller 之外的规则层」：
把状态白名单、访问边界、幂等、字段白名单收口为可单测的 policy 纯函数，
controller 只做接入与业务查询——UI 或后续模块不得另建一套状态口径。

**约束**：不改 Prisma schema/migrations；不碰 `backend/data/village.db`；
不手改生成产物；不改变既有业务语义（characterization 锁定现状行为）；
测试全部使用临时合成 SQLite（`backend/prisma/.test-*` 前缀）并确定性清理。
