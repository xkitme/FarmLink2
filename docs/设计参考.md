## 设计系统：Agro-Modernist Tech（农业现代科技风）

理念：连接土壤与云端的「科技活力」，专业可靠 + 有机生长 + 易用创新。
高对比、大触控目标，适配户外强光与农户/田间操作者。

### 字体
Noto Sans 全级别。标题粗体、紧字距；正文宽行高；标签半粗 + 宽字距。

### 形状 / 圆角
- 卡片/容器：16px（1rem）
- 大容器：32px（2rem）
- 按钮：full 胶囊形

### 阴影（柔和棕调环境光）
`box-shadow: 0px 4px 20px rgba(121,85,72,0.05)` —— 禁用浓黑阴影。

### 关键组件
- **顶栏**：白底 sticky，左农机图标、居中「FarmLink 田园通」粗体绿、右通知铃铛
- **底栏**：白底、顶部 32px 圆角、上方柔影；激活 Tab 用 primary-container 20% 底色胶囊
- **底栏 Tab**：首页 / AI 农技 / 发布 / 消息 / 我的
- **按钮**：主按钮胶囊形实心绿；次按钮胶囊棕色描边；幽灵按钮绿字
- **卡片**：白底 16px 圆角 + 环境光阴影；AI 卡片加 1px 麦金内描边
- **预警横幅**：顶部 error 红 / warning 橙，白字 + 前导图标
- **输入框**：浅白填充、底部 2px 棕色边、标签常驻
