## 任务

### A. 扩展 `InfoDetailPage` 支持「可选底部主操作按钮」
- 给 `InfoDetailData` 增加两个可选字段：
  ```dart
  final String? actionLabel;      // 例如 '响应互助' / '确认缴费'
  final VoidCallback? onAction;   // 点击回调，由调用页传入
  ```
  构造函数加上 `this.actionLabel, this.onAction`（保持其余字段不变、保持 `const`）。
- 在 `InfoDetailPage.build` 的 ListView 末尾，当 `data.actionLabel != null && data.onAction != null` 时，渲染一个整宽 `ElevatedButton`：
  ```dart
  SizedBox(
    width: double.infinity,
    child: ElevatedButton(
      onPressed: () {
        if (context.canPop()) context.pop();
        data.onAction!.call();
      },
      child: Text(data.actionLabel!),
    ),
  )
  ```
  （先 pop 回到来源页，再执行动作——动作里的 toast/刷新都发生在来源页，context 有效。）
  按钮上方留 `SizedBox(height: 20)`。样式沿用主题，不要自定义大圆角/渐变。

### B. `about_page.dart`：服务协议 / 隐私政策 → 详情页

- 需要 `import 'package:go_router/go_router.dart';` 和 `import '../../common/info_detail_page.dart';`（按 about_page 实际相对路径调整层级）。

### C. `life_page.dart`：邻里互助详情 + 水电气账单 → 详情页（带动作按钮）
- `_helpDetail(Map h)`（约 1116 行，原 `_sheet('...邻里互助', child: 内容 + 响应互助按钮)`）：
  改为 `context.push('/detail/info', extra: InfoDetailData(title: h['title'], body: 内容文本, actionLabel: '响应互助', onAction: () => _acceptHelp(h)))`。
  正文把 `content` + （若有）`联系电话：xxx` 拼成 `body`。
- `_utilitySheet()` 里查到 `bill` 后那段 `_sheet('...账单', child: 账单信息 + 确认缴费按钮)`（约 770 行）：
  改为 `context.push('/detail/info', extra: InfoDetailData(title: '${...}账单', body: '账期/应缴金额/截止日期' 文本, actionLabel: '确认缴费', onAction: () => _payUtility(type.value, bill['amount'])))`。
  注意 `_utilitySheet` 是 async，push 前先判 `if (!mounted) return;`（原代码已有）。
- 这两处改完后，`life_page.dart` 里的私有 `_sheet(String title, {required Widget child})` 若不再被任何地方调用，则删除它（避免 unused 警告）。先全文件搜 `_sheet(` 确认无其它调用再删。
