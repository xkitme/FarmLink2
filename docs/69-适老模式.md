# 69 · 适老模式（#20a，Codex 实施）

> **目标**：设置页的「适老模式」开关真正生效——开启后全局字号放大、点触更友好，
> 关闭恢复原状，状态持久化、重进 App 保持。对外口径「在线 SaaS 平台」。

## 背景
- GitHub issue #20 第一半：提供适老模式。`user.isElderMode` 字段**已存在**（`app/lib/models/user.dart`）。
- `app/lib/main.dart` **已有全局 textScaler**（当前 clamp 0.9~1.1，见第 78~99 行）。适老就接这里放大。

## 改动清单（按文件）

1. **适老状态（新建一个轻量状态）**
   - 优先复用现有的 auth/用户全局状态（如果已有 `ChangeNotifier` 管 `User`，就在它上面加 `bool elderMode` + `setElderMode()`）；没有就新建 `app/lib/core/elder_mode.dart` 一个小 `ChangeNotifier`。
   - 初值：读当前登录用户的 `isElderMode`；本地持久化用 `SharedPreferences`（key `elder_mode`），下次启动先读本地。

2. **`app/lib/main.dart` 全局放大**
   - 当 elderMode 开：`textScaler` 目标放到约 **1.3**，clamp 上限提到 ~1.35；关闭时维持现有 0.9~1.1 行为。
   - 只动 textScaler 相关那段，别重写整个 builder。

3. **设置页开关 `app/lib/pages/profile/settings/settings_home_page.dart`**
   - 加一行「适老模式」开关（用页面/项目既有的 SettingTile / SwitchListTile 风格，见 `settings_widgets.dart`），副标题如「放大字号，方便长辈使用」。
   - 切换时：更新适老状态 + 持久化；**best-effort** 调既有 `PUT /user/profile` 把 `isElderMode` 同步到后端（用现有 api_client 方法，**不要修改 api_client.dart**；接口若不收该字段就只本地持久化，不报错）。

## 验收

- 开关 → 全局字号肉眼变大、布局不溢出；关 → 恢复。
- 重进 App（杀进程再开）状态保持。
