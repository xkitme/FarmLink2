# 分段 31 — 存量文案口径回扫

## 目标

按 `docs/产品呈现口径.md` 对存量文案做一次全量回扫，确保用户界面、管理台、接口调试说明和 README 统一呈现为正式在线服务平台口径。

## 扫描范围

- Flutter App：`app/lib/**`
- Ant Design Pro 管理台：`backend/admin/src/**`
- 后端用户可见返回与接口说明：`backend/src/**`
- 对外说明入口：`README.md`

## 本次调整

1. 移动端 Toast、空态、加载态统一改为「服务暂时不可用」「正在处理中」「待发送队列」等中性表达。
2. AI 页面去掉技术实现暴露，识别、问答、语音相关提示统一按「AI 服务」呈现。
3. 数据看板、个人中心、发布中心等同步文案统一为「数据同步 / 待发送队列」。
4. 管理台登录页、菜单、仪表盘、API 调试目录、API 开关页去掉部署属性描述，改为数据治理与服务状态表达。
5. 后端提示语中面向用户的规则模板、政策库、快递、贷款、农机诊断等文案改为平台服务表达。
6. README 项目简介、核心特点、功能表、技术架构和 AI 说明改为在线服务平台口径。

执行存量文案回扫命令（实际执行时使用 `docs/产品呈现口径.md` 中的禁用词清单）：

```powershell

```
