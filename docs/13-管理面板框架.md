# 分段 13 — Ant Design Pro 管理面板：框架 + 登录 + 布局

> 状态：✅ 完成  
> 执行时间：2026-05-21  
> 执行原则：继续现有项目，不清空、不覆盖旧 `docs` 记录。

## 本次任务目标

创建后端管理面板基础框架，为后续 P14/P15 的业务数据 CRUD、API 开关管理和 API 在线调试器做准备。

本阶段只做：

- 管理面板项目目录。
- 登录页。
- 主布局、菜单、路由。
- 请求封装、登录态持久化。
- 驾驶舱首页。
- 后端生产模式 `/admin` 静态托管。

## 技术选型

管理台目录：`backend/admin`

| 项 | 选型 |
|---|---|
| 构建 | Vite |
| 前端框架 | React 18 |
| UI | Ant Design 5 |
| Pro 能力 | `@ant-design/pro-components` |
| 路由 | React Router |
| 后端接口 | `/api/v1` |

## 执行内容

### 1. 管理面板项目

新增 `backend/admin/package.json`：

```text
npm run dev      Vite 开发服务
npm run build    生产构建
npm run preview  本地预览
```

后端根目录原有脚本可继续使用：

```text
npm run install:all
npm run dev
npm run build:admin
npm run start
```

### 2. Vite 配置

新增 `backend/admin/vite.config.js`：

- `base: '/admin/'`
- 开发服务端口：`5173`
- `/api` 代理到 `http://localhost:8000`
- `/uploads` 代理到 `http://localhost:8000`

### 3. 登录页

新增 `Login.jsx`：

- 调用 `POST /api/v1/auth/login`
- 默认填入测试账号：`admin / 123456`
- 仅允许 `ADMIN` 角色进入后台
- 登录后写入 localStorage：
  - token
  - refreshToken
  - user

### 4. 请求封装

新增：

- `src/api/request.js`
- `src/api/auth.js`

能力：

- 自动拼接 `/api/v1`
- 自动携带 `Authorization`
- 统一处理后端响应 `{ code, msg, data, timestamp, traceId }`
- `40101` 自动清理登录态并跳转登录页

### 5. 主布局与菜单

新增 `AdminLayout.jsx`：

- 左侧菜单
- 顶部栏
- 用户头像与退出登录
- 按 8 大业务板块预留菜单
- 预留 AI 管理、API 在线调试、API 开关、操作日志入口

菜单路由包括：

```text
/dashboard
/users
/agri
/market
/machinery
/disaster
/policy
/life
/data
/ai
/api-switch
/api-debug
/logs
```

### 6. 驾驶舱首页

新增 `Dashboard.jsx`：

调用：

- `GET /api/v1/data/dashboard`
- `GET /api/v1/ai/status`
- `GET /api/v1/admin/api-switch/list`

展示：

- 用户总数
- 地块数量
- 管理面积
- 农事记录
- 订单金额
- 灾损估算
- 政策条目
- AI 记录
- 作物面积分布
- API 开关概览
- 离线状态

### 7. 后端 `/admin` 托管

修改 `backend/src/app.js`：

- `app.use('/admin', express.static(adminDist))`
- `app.get('/admin/*', ...)` 回退到 `index.html`

生产模式执行：

```bash
npm run build:admin
NODE_ENV=production node src/server.js
```

即可访问：

```text
http://localhost:8000/admin/login
```
