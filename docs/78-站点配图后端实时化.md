# 78 - 站点配图后端实时化

## 目标

让项目引用的**所有站点配图**都能从后端实时更新——运维替换后端图片文件即生效，
无需重新编译 / 发布 App。bundled 资产降级为离线/首载兜底。

## 核查：改造前的图片引用

`Image.asset(...)`（写死在 bundle，不可后端更新）共 13 处，覆盖：
- 登录/注册 hero、设置页 banner（auth-hero）
- 引导页/首页横幅（smart-farming / farm-market / machinery-sharing）
- 乡村生活 hero/缩略（rural-life / rural-tourism）
- 农机地图底图（farmland-map）、气象设置 banner（weather-monitoring）
- 政策三 tab fallback（policy-support / community-learning / village-honor）
- 集市/商品详情 SKU 兜底（product-\*）
- 顶栏品牌 logo（farmlink-mark.png）

服务端数据图（market/policy/machinery/life 的 `/uploads/...`）已走 `resolveImageUrl`
可后端更新，本批不动。

## 方案

约定：站点图统一从后端 `/uploads/site/<文件名>` 加载，bundled 同名资产作兜底。
后端替换 `uploads/site/` 下文件即实时更新前端配图。

### 后端

- 站点图入库：`backend/uploads/site/`（20 张，与前端 bundled 同名）。`/uploads`
  已由 `express.static` 服务，故 `/uploads/site/<file>` 直接可访问。
  `backend/.gitignore` 加例外（`!uploads/site/`）让站点图随仓库发布（离线自包含），
  用户上传文件仍忽略。
- `platform/site.controller.js` + 路由：
  - `GET /api/v1/site/images`（公开）：读取 `uploads/site/` 返回
    `{ images: { <key>: "/uploads/site/<file>" } }`，key=去扩展名文件名。
  - `POST /api/v1/site/images/:key`（**管理员**，multipart `file`）：覆盖
    `uploads/site/<key>.<ext>`（先删同 key 旧文件避免多扩展名并存），返回新 url。

### 管理台（`backend/admin/`）

- 新增「**站点配图**」页（`pages/SiteImagePage.jsx`，系统治理菜单下）：
  网格展示全部站点图（中文用途标签 + key + 预览），每张「上传替换」按钮，
  上传成功后时间戳打破缓存即时显示新图，并提示"前端下次加载即生效"。
- App.jsx 加路由 `/site-images`，AdminLayout 加菜单项（PictureOutlined）。

### 前端

- 新增 `core/site_images.dart`：
  - `SiteImages.remoteUrl(asset)`：`assets/images/<file>` → 后端 `/uploads/site/<file>` 绝对 URL。
  - `SiteImage` 组件：`Image.network`（后端图）优先，加载中/失败回落 `Image.asset`（bundled）。
    等价替换 `Image.asset`，支持 width/height/fit/filterQuality/errorFallback。
- 13 处 `Image.asset` 全部替换为 `SiteImage`；各页原有 `/uploads`、`http` 网络分支不变。
- bundled 资产**保留**在 pubspec（离线/首载兜底，后端不可达时 App 仍有图）。

## 验证

- `flutter analyze lib`：No issues found；`npm run build`（admin）通过。
- 后端：`GET /site/images` 返回 20 项；`/uploads/site/auth-hero.jpg` 静态 200；
  `POST /site/images/policy-support`（admin token + multipart）→ 200，磁盘文件
  实际被覆盖（218891→340910 字节）。
- **release 浏览器实测通过（端到端实时更新）**：
  - 登录页加载时网络请求命中 `/uploads/site/auth-hero.jpg`（配图确走后端）。
  - 把后端 `uploads/site/auth-hero.jpg` 替换为另一张图后**仅重载页面**（App 未重编），
    登录 hero 实时变为新图 → 证明「后端换图即生效」。
- ⚠️ 顺带修复：web build 默认从 gstatic CDN 拉 canvaskit/字体，**离线环境会白屏**；
  改用 `flutter build web --no-web-resources-cdn` 自托管 canvaskit（已同步
  `scripts/start-local.ps1`）。字体仍可能联网拉 Google Fonts，离线下回落系统字体。
