# 语音助手「呼叫唤起 + 可拖动靠边小球」设计

> 日期：2026-06-21 · 状态：已与用户确认，待实现
> 相关文件：`app/lib/widgets/voice_assistant_layer.dart`、`app/lib/pages/home/shell_page.dart`、
> `backend/src/modules/ai/services/assistant-config.service.js`、`backend/admin/src/pages/AiAssistantPage.jsx`

## 目标

1. **呼叫唤起**：用户说「你好小田」时唤起 AI 语音助手；唤醒词可在后端管理台配置（支持多个）。
2. **小球收敛**：悬浮小球变小、默认位置放低一点。
3. **可拖动只靠边**：小球可拖动，但松手只能吸到屏幕左/右边缘；拖动后的位置跨页面、重启都记住。

## 关键决策（已与用户确认）

- 唤醒常听走**设置开关，默认关**（持续占用麦克风，隐私/耗电考虑）。
- 唤醒词在**管理台 AI 语音助手页**配置，**支持多个**（逗号/换行分隔）。
- 拖动位置**持久化**：跨页面 + 重启都保留。
- 唤醒入口用**独立设置页**（可解释「持续监听麦克风」）。
- 唤醒词匹配用**模糊匹配**（归一化 + 包含 + 近音字重叠），容忍 STT 同音错字。

## 范围边界

- Web 无离线真识别（sherpa = dart:ffi，仅 APK）。**Web 端唤醒词不生效**，保留点击/拖动小球唤起；真识别只能 APK 真机验。
- 不动工作树里 `offline_stt_io.dart` 现有未提交的诊断日志改动（非本功能）。

## A. 可拖动靠边小球（变小 + 放低 + 记位置）

**视觉**
- 尺寸 `54 → 46`。
- 默认位置：贴右边，纵向从 `bottom:150` 下移到约 `bottom:96`（仍在底部导航栏之上）。

**交互**
- `GestureDetector` 的 `onPanStart/onPanUpdate/onPanEnd` 实现拖动：拖动时跟手自由移动。
- 松手（`onPanEnd`）后用 `AnimatedPositioned` **吸到最近的左/右屏幕边**；纵向 `clamp` 在安全范围（顶部状态栏下 ~ 底部导航栏上）。
- 拖动 vs 点击区分：累计位移 < ~8px 判定为**点击**→ `_activate()`；否则为拖动，不触发唤起。

**持久化**
- `SharedPreferences` 存：
  - `voice_orb_side`：`'left'` / `'right'`
  - `voice_orb_top_frac`：`0.0~1.0` 纵向比例（按比例存，适配不同屏高）
- 小球状态由 `_orbSide` + `_orbTopFrac` 驱动 `Positioned`。初始化时读取，松手吸边后写入。

## B. 唤醒词「你好小田」（设置开关默认关）

**新增 `app/lib/core/voice_wake.dart`**（仿 `core/elder_mode.dart` 的 `ElderModeState`）：
- `class VoiceWakeState extends ChangeNotifier`
- 字段：`bool enabled`（本地 pref `voice_wake_enabled`，默认 `false`）、`List<String> wakeWords`（默认 `['你好小田']`）。
- `init()`：读本地开关；向后端 `GET /ai/assistant/config` 拉 `wakeWords`（失败兜底默认词，不抛）。
- `setEnabled(bool)`：写 pref + `notifyListeners()`。
- 在 `app/lib/main.dart` 的 `MultiProvider` 注册，随启动 `init()`（仿 `_elderMode.init`）。

**新增设置页** `app/lib/pages/profile/settings/wake_word_page.dart`（仿适老模式介绍页）：
- 路由 `/profile/settings/wake`（`router.dart` 注册）。
- 内容：标题/说明「开启后将持续用麦克风离线监听唤醒词，听到即唤起 AI 语音助手」「仅 APK 真机可用」「当前唤醒词：<wakeWords>」+ 底部启用开关（`VoiceWakeState.setEnabled`）。
- 设置首页 `settings_home_page.dart`「通知与通用」组加一行入口（`SettingTile`，trailingText 显示「已开启/未开启」）。

**`VoiceAssistantLayer` 接入常听**：
- 监听 `VoiceWakeState`（`context.watch` 或在 `didChangeDependencies` 订阅）。
- 触发常听条件：`widget.enabled（在 5 个一级 tab）&& wakeEnabled && !kIsWeb && !_active`。
- 常听实现：复用 `OfflineStt.start(onText:..., onEndpoint:...)`，`onText` 里对识别文本做模糊匹配命中唤醒词 → 先 `OfflineStt.stop()` 停常听 → `_activate()`。
- 协调：常听与激活态共用同一个 `OfflineStt` 单例。切换任一模式前先 `await OfflineStt.stop()`，保证只有一个消费者、不抢麦。新增 `bool _wakeListening` 标记当前是否在常听。
- 生命周期：`_activate()` 前停常听；`_deactivate()` 后若 `wakeEnabled` 仍为真则恢复常听；开关被关掉时停常听；`widget.enabled` 变 false（离开一级 tab）时停常听。

**模糊匹配**（新增私有方法，复用 `_normForEcho` 归一化）：
- 归一化识别文本与每个唤醒词（去标点空白）。
- 命中规则：识别文本 `contains` 唤醒词归一化串 → 命中；或与唤醒词等长且字重叠率 ≥ ~0.75（容忍同音错字如「你好小天」）→ 命中。
- 唤醒词短（~4 字），以 `contains` 为主；只在末尾最近一段文本上判断，避免常听累计文本误判。

## C. 后端管理唤醒词

**`backend/src/modules/ai/services/assistant-config.service.js`**：
- `normalize()` 增加 `wakeWords`：从 `raw.wakeWords` 读（接受数组或逗号/换行字符串），规整为去空去重的字符串数组；为空时回落 `['你好小田']`。新增 `DEFAULT_WAKE_WORDS = ['你好小田']`。
- `getAssistantConfigView()` 带上 `wakeWords`。
- `saveAssistantConfig(patch)`：处理 `patch.wakeWords`（字符串或数组 → 数组，限数量 ≤ 8、单词长度 ≤ 20、整体长度兜底），存库。

**管理台 `backend/admin/src/pages/AiAssistantPage.jsx`**：
- 在「系统提示词」卡附近加「唤醒词」输入项（`Input.TextArea`，提示「逗号或换行分隔多个，留空用默认『你好小田』」）。
- `load()` 回填、`handleSave()` 提交（字符串原样提交，服务端负责拆分）。

**App 读取端点**：
- `backend/src/modules/ai/ai.routes.js` 加 `router.get('/ai/assistant/config', wrap(ai.assistantConfig))`（已在 `/ai` 下 `requireAuth`）。
- `ai.controller.js` 新增 `assistantConfig`：`loadAssistantConfig()` 后**只回 `{ enabled, wakeWords }`，绝不回 DeepSeek key / systemPrompt 等敏感字段**。

## 数据流

```
管理台改唤醒词 → saveAssistantConfig 存 SiteSetting:ai_assistant_config
App 启动 → VoiceWakeState.init() → GET /ai/assistant/config → wakeWords
用户在设置页开「语音唤醒」→ VoiceWakeState.enabled=true (pref)
在一级 tab 页 → VoiceAssistantLayer 启动 OfflineStt 常听
说「你好小田」→ onText 模糊命中 → stop 常听 → _activate() → 进入既有语音助手流程
助手关闭 → 若仍开 → 恢复常听
```

## 错误处理与降级

- 后端 `GET /ai/assistant/config` 失败：App 用兜底唤醒词 `['你好小田']`，开关功能不受影响。
- `OfflineStt` 不可用 / 无麦克风权限 / 非 APK：常听静默不启动（不报错、不崩），小球点击/拖动照常。
- 管理台唤醒词非法（过长/过多）：`errors.param` 拦截。

## 验收

- 后端：`node --check`；`GET /ai/assistant/config` 只回 `{enabled, wakeWords}`；管理台改词 round-trip。
- 前端：`flutter analyze`；浏览器实测小球拖动吸边 + 位置持久化 + 设置页开关；
  **唤醒词真识别（说「你好小田」唤起）只能 APK 真机验**——前端改动必须重打 APK。

## 不在范围

- 唤醒词的声学自定义训练 / KWS 专用模型（仍走通用 sherpa STT + 文本匹配）。
- Web 端真唤醒。
- 多语言唤醒词。
