## 任务

### A. AppCard 列表项 → 扁平分区行
- 把这两页里**展示型** `AppCard(...)`（即点进去只是看详情、没有就地操作按钮的卡）改成扁平容器：
  ```dart
  Container(
    decoration: BoxDecoration(
      color: AppColors.surface,
      borderRadius: BorderRadius.circular(R.sm),
      border: Border.all(color: AppColors.outlineVariant, width: 1),
    ),
    // 无 boxShadow
    ...
  )
  ```
  或在同质列表里改成「白底 + 1px 分隔线（`Divider(height:1,color: AppColors.outlineVariant)`）」的平铺行，去掉卡片间距浮起感。两种取其一，按该 section 现有结构选更自然的。
- **不要删 `AppCard` 这个类**（别处仍在用）；只是这两页内不再用它来包列表项。

### B. 点击项 / 展示型弹层 → 跳详情页
- 列表项点击、以及现有 `showModalBottomSheet` / 私有 `_sheet(...)` / `_infoSheet(...)` 等**纯展示型**弹层，
  一律改为：
  ```dart
  context.push('/detail/info', extra: InfoDetailData(
    title: 标题,
    body: 正文,            // 或
    sections: [InfoSection(subtitle: ..., body: ..., items: [...])],
    actionLabel: '可选主操作',  // 仅当原弹层底部有单个主按钮时
    onAction: () => 原回调,
  ));
  ```
- 若原弹层是**操作型**（含表单 / 多按钮 / 就地编辑），本轮**保留不动**，只处理展示型。拿不准的写进实施备注，别硬改。

### C. 口径
- 文案遵守 `docs/产品呈现口径.md`：在线 SaaS 定位，**禁**「离线 / 断网 / 本地兜底」等词。
- 数据加载、业务逻辑、跳转目标语义保持不变，只改呈现层。
