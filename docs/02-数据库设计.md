### 2. 设计要点
- SQLite **不支持 Json 类型** → JSON 字段统一用 `String` 存 JSON 文本，控制器负责 parse/stringify
- 金额/面积用 `Float`，日期用 `DateTime`
- 业务表带 `localUuid` 字段支持离线同步去重
- 用标量外键字段（userId 等）+ `@@index`，不定义 Prisma 关系（60 表规模下更清晰）
- 状态/角色/类型用 `String` + 注释（SQLite 无 enum）
