# 105 · 语音助手「朗读途中打断说话」按钮（barge-in）

## 目标
新增功能点：助手正在朗读回复时，点左下角按钮即可**打断 TTS、立刻切回聆听**，不必等它念完。

## 背景
原左下角按钮固定是「提交」；助手朗读期间（`speakAndWait` 阻塞中）麦克风没开，用户只能干等念完。需要一个手动打断入口。

## 改动 `app/lib/widgets/voice_assistant_layer.dart`
- 新增 `_speaking` 状态：朗读前置 true、念完/被打断置 false（`_deactivate` 也复位）。
- 左下角按钮按状态切换：朗读中=「打断说话」(mic 图标)→ `_interruptAndListen`；否则=「提交」→ `_submitRecognized(auto:false)`。
- `_interruptAndListen`：调 `TtsService.stop()`。它会让正在 await 的 `speakAndWait` 立即返回，`_submitRecognized` 的 finally 随即重新开麦，状态从「播报」自动切到「聆听」——无需手动开麦。
- 底栏中部提示与状态文案在朗读态显示「正在播报，点左下角可打断说话」。

## 契约
不改接口、命令白名单、STT/TTS 实现。纯前端交互态。

## 验收
- `flutter analyze lib/widgets/voice_assistant_layer.dart` → No issues found。
- 需 APK 复验：助手朗读时点左下角，朗读立即停、底栏切到「聆听中…」、可直接接着说。

## 备注
- 这是手动打断；朗读后自动开麦的留守问题（模拟器 flutter_tts 完成回调不可靠）属另一议题，用户已要求保持连续聆听、后续单独处理。
