## 核心做法（极简、零风险）

各页都有一份私有 `Future<bool?> _formSheet({required String title, required List<Widget> fields})` helper（几十个录入表单都调它）。
**只改这个 helper 的实现体**，从 `showModalBottomSheet(...)` 换成 push 共享整页：

```dart
Future<bool?> _formSheet(
    {required String title, required List<Widget> fields}) {
  return Navigator.of(context, rootNavigator: true).push<bool>(
    MaterialPageRoute(
      builder: (_) => FormScaffoldPage(title: title, fields: fields),
    ),
  );
}
```

- 顶部加 `import '../common/form_scaffold_page.dart';`（按各文件实际相对层级，service 页在 `pages/policy/` 等，路径为 `../common/form_scaffold_page.dart`）。
- **调用点、`_field`/`_chipsField`、所有 `TextEditingController` 全不动**——返回语义不变（提交=true / 返回=false）。
- 若某页 `_formSheet` 签名带额外参数（如 `submitText`/`submitLabel`/`okText`），传给 `FormScaffoldPage(submitLabel: ...)`；FormScaffoldPage 默认 `submitLabel='提交'`。
- 改完后该页若 `showModalBottomSheet` 仅 `_formSheet` 用到、且无其它引用导致 unused import（如 `R.lg` 等）—— 不必强清，但别引入新 warning。
