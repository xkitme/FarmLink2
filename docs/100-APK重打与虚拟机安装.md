# 分段 100 — APK 重打与虚拟机安装

> 执行日期：2026-06-18

## 一、目标

- 把当前 HEAD 的 Flutter App 构建为 Android release APK。
- 将 APK 安装到本机 Android 11 x86_64 模拟器并完成冷启动检查。
- 验证离线 STT 模型、x86_64 Flutter 引擎和模拟器后端连通性。

## 二、构建阻断与修复

首次构建在 `compileFlutterBuildRelease` 失败：`record_linux 0.7.2` 未实现
`record_platform_interface 1.6.0` 新增的 `startStream` 契约，且 `hasPermission`
签名不一致。该问题来自 `record 5.2.1` 的宽松传递依赖约束。

最小修复：

- `app/pubspec.yaml`：`record` 从 `^5.1.2` 升到 `^6.2.1`。
- `app/pubspec.lock`：同步解析 `record 6.2.1`、`record_linux 1.3.1` 及配套平台包。
- 现有 `AudioRecorder`、`RecordConfig`、`startStream` 业务调用无需修改。

## 三、构建与安装

构建命令：

```powershell
.\scripts\build-apk.ps1 -ApiBaseUrl 'http://10.0.2.2:8000' -Mode release
```

说明：`10.0.2.2` 是 Android Emulator 访问宿主机的专用地址，宿主机后端监听
`8000` 端口。

产物：

- 路径：`dist/FarmLink.apk`
- 大小：`368,519,944` 字节（约 351.4 MB）
- SHA-256：`017C98349459509E7DD124D43D6A95988460CB6BD061A570850AF6A522F42158`
- App 版本：`1.8.0+18`

安装命令：

```powershell
adb -s emulator-5554 install -r dist\FarmLink.apk
```

结果：`Success`。
