# 分段 45b — 拍照一键全闭环（招牌场景 A1）

> 工作单（Codex 实施）。所属 lane：[45-招牌场景与产品重构计划](45-招牌场景与产品重构计划.md) Lane A · A1。
> demo 高光镜头之一。**复用现有接口，不新增后端端点。**
> 完成后 `flutter analyze lib` + `node --check`，commit 中文，进度总览改 ✅。

## 一、目标（一句话能复述）

「拍一张叶子 → 30 秒 AI 给出病害 + 农药剂量 → 一键建档当天用药 + 自动排 7 天后复查 → 农事日历出现两条待办」。

把现有的 4 个分散能力（识病 / 农药查询 / 农事记录 / 日历）串成**单页引导流程**，演示时一气呵成。

## 二、demo 剧本（验收即按此走）

主角张大叔（farmer 账号，45a 已铺数据）：

1. 首页/农业板块点「智能植保」→ 进入 `/agri/diagnose`
2. 拍/传一张苹果叶片照片
3. 识别结果卡：「苹果黑星病（早期） 94.8%」+ 防治建议 + 推荐农药「多菌灵 500 倍液」
4. 点「一键建档并提醒复查」→ 确认 sheet（今日喷药记录 + 7 天后复查待办）
5. 提交 → toast「已加入农事日历，7 天后将提醒复查」
6. 跳「我的农事记录」→ 看到今日「打药 · 苹果黑星病防治」+ 未来「复查 · 黑星病防治效果」两条

### 1. 新建 `app/lib/pages/agri/diagnose_page.dart`

```dart
import 'dart:typed_data';
import 'package:flutter/material.dart';
import 'package:go_router/go_router.dart';
import 'package:image_picker/image_picker.dart';
import '../../core/api_client.dart';
import '../../core/constants.dart';
import '../../widgets/common.dart';

class DiagnosePage extends StatefulWidget {
  const DiagnosePage({super.key});
  @override
  State<DiagnosePage> createState() => _DiagnosePageState();
}

class _DiagnosePageState extends State<DiagnosePage> {
  final _picker = ImagePicker();
  Uint8List? _image;
  String? _imageName;
  bool _detecting = false;
  bool _archiving = false;
  Map<String, dynamic>? _result;   // { resultLabel, confidence, disease:{...} }

  Future<void> _pick(ImageSource source) async {
    final img = await _picker.pickImage(source: source, imageQuality: 82, maxWidth: 1600);
    if (img == null) return;
    final bytes = await img.readAsBytes();
    if (!mounted) return;
    setState(() {
      _image = bytes;
      _imageName = img.name;
      _result = null;
      _detecting = true;
    });
    await _detect();
  }

  Future<void> _detect() async {
    try {
      final data = await ApiClient.upload(
        '/agri/disease/detect',
        _image!, _imageName ?? 'leaf.jpg',
      ) as Map<String, dynamic>;
      if (!mounted) return;
      setState(() {
        _result = data;
        _detecting = false;
      });
    } catch (e) {
      if (!mounted) return;
      setState(() => _detecting = false);
      toast(context, actionErrorMessage('识别', e), error: true);
    }
  }

  Future<void> _archive() async {
    if (_result == null || _archiving) return;
    final disease = (_result!['disease'] as Map?)?.cast<String, dynamic>() ?? {};
    final label = '${_result!['resultLabel'] ?? disease['diseaseName'] ?? '病害'}';
    final medicine = '${disease['medicineAdvice'] ?? disease['prevention'] ?? '按标签施药'}';
    final cropType = '${disease['cropType'] ?? ''}';

    final confirmed = await _confirmSheet(label, medicine, cropType);
    if (confirmed != true || !mounted) return;

    setState(() => _archiving = true);
    final today = DateTime.now();
    final recheck = today.add(const Duration(days: 7));
    try {
      // 1. 今日用药记录
      await ApiClient.post('/agri/record', body: {
        'recordType': '打药',
        'cropType': cropType,
        'content': '$label 防治：$medicine',
        'recordDate': today.toIso8601String(),
      });
      // 2. 7 天后复查待办
      await ApiClient.post('/agri/record', body: {
        'recordType': '复查',
        'cropType': cropType,
        'content': '$label 防治效果复查（用药后第 7 天）',
        'recordDate': recheck.toIso8601String(),
      });
      if (!mounted) return;
      toast(context, '已加入农事日历，7 天后将提醒复查');
      context.go('/agri');   // 回农业板块（农事记录列表在那）
    } catch (e) {
      if (mounted) toast(context, actionErrorMessage('建档', e), error: true);
    } finally {
      if (mounted) setState(() => _archiving = false);
    }
  }

  Future<bool?> _confirmSheet(String label, String medicine, String crop) {
    return showModalBottomSheet<bool>(
      context: context,
      backgroundColor: AppColors.surface,
      shape: const RoundedRectangleBorder(
        borderRadius: BorderRadius.vertical(top: Radius.circular(R.lg)),
      ),
      builder: (ctx) => Padding(
        padding: const EdgeInsets.fromLTRB(20, 18, 20, 28),
        child: Column(
          mainAxisSize: MainAxisSize.min,
          crossAxisAlignment: CrossAxisAlignment.start,
          children: [
            const Text('建档预览',
                style: TextStyle(fontSize: 18, fontWeight: FontWeight.w700)),
            const SizedBox(height: 14),
            _previewRow(Icons.medication_outlined, '今日',
                '$label 防治：$medicine'),
            const SizedBox(height: 10),
            _previewRow(Icons.event_repeat_outlined, '7 天后',
                '$label 防治效果复查'),
            const SizedBox(height: 18),
            SizedBox(
              width: double.infinity, height: 48,
              child: ElevatedButton(
                onPressed: () => Navigator.pop(ctx, true),
                child: const Text('确认建档'),
              ),
            ),
          ],
        ),
      ),
    );
  }

  Widget _previewRow(IconData icon, String tag, String text) => Row(
    crossAxisAlignment: CrossAxisAlignment.start,
    children: [
      StatusChip(tag, color: AppColors.primary),
      const SizedBox(width: 10),
      Expanded(child: Text(text, style: const TextStyle(height: 1.4))),
    ],
  );

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      backgroundColor: AppColors.background,
      appBar: AppBar(
        backgroundColor: AppColors.background,
        elevation: 0,
        leading: IconButton(
          icon: const Icon(Icons.arrow_back, color: AppColors.primary),
          onPressed: () => context.canPop() ? context.pop() : context.go('/agri'),
        ),
        title: const Text('智能植保',
            style: TextStyle(color: AppColors.primary, fontSize: 20, fontWeight: FontWeight.w700)),
      ),
      body: ListView(
        padding: const EdgeInsets.fromLTRB(16, 8, 16, 28),
        children: [
          _heroCard(),
          const SizedBox(height: 16),
          _uploadArea(),
          if (_detecting) ...[
            const SizedBox(height: 24),
            const Loading(text: 'AI 正在识别叶片...'),
          ],
          if (_result != null && !_detecting) ...[
            const SizedBox(height: 16),
            _reportCard(),
            const SizedBox(height: 16),
            SizedBox(
              width: double.infinity, height: 52,
              child: ElevatedButton.icon(
                onPressed: _archiving ? null : _archive,
                icon: _archiving
                    ? const SizedBox(width: 18, height: 18, child: CircularProgressIndicator(color: Colors.white, strokeWidth: 2))
                    : const Icon(Icons.fact_check_outlined),
                label: Text(_archiving ? '建档中' : '一键建档并提醒复查'),
              ),
            ),
            const SizedBox(height: 10),
            SizedBox(
              width: double.infinity, height: 48,
              child: OutlinedButton.icon(
                onPressed: () => _pick(ImageSource.camera),
                icon: const Icon(Icons.refresh, size: 18),
                label: const Text('重新拍照'),
              ),
            ),
          ],
        ],
      ),
    );
  }

  Widget _heroCard() => Container(
    padding: const EdgeInsets.all(18),
    decoration: BoxDecoration(
      gradient: AppColors.heroGradient,
      borderRadius: BorderRadius.circular(R.lg),
      boxShadow: AppColors.ambientShadow,
    ),
    child: const Row(
      children: [
        Icon(Icons.biotech_outlined, color: Colors.white, size: 36),
        SizedBox(width: 14),
        Expanded(
          child: Column(
            crossAxisAlignment: CrossAxisAlignment.start,
            children: [
              Text('AI 智能植保 · 一拍即诊',
                  style: TextStyle(color: Colors.white, fontSize: 19, fontWeight: FontWeight.w700)),
              SizedBox(height: 4),
              Text('拍照识别病虫害，自动生成防治方案并排程复查',
                  style: TextStyle(color: AppColors.onPrimaryContainer, fontSize: 12, height: 1.4)),
            ],
          ),
        ),
      ],
    ),
  );

  Widget _uploadArea() => InkWell(
    borderRadius: BorderRadius.circular(R.md),
    onTap: _detecting ? null : _chooseSource,
    child: Container(
      height: _image == null ? 160 : 220,
      decoration: BoxDecoration(
        color: AppColors.surfaceLow,
        borderRadius: BorderRadius.circular(R.md),
        border: Border.all(color: AppColors.outlineVariant, width: 2),
      ),
      child: _image == null
          ? const Column(
              mainAxisAlignment: MainAxisAlignment.center,
              children: [
                Icon(Icons.add_a_photo_outlined, size: 36, color: AppColors.outline),
                SizedBox(height: 8),
                Text('拍照或上传叶片照片', style: TextStyle(color: AppColors.onSurfaceVariant)),
              ],
            )
          : ClipRRect(
              borderRadius: BorderRadius.circular(R.md - 2),
              child: Image.memory(_image!, fit: BoxFit.cover, width: double.infinity),
            ),
    ),
  );

  void _chooseSource() {
    showModalBottomSheet(
      context: context,
      backgroundColor: AppColors.surface,
      builder: (ctx) => SafeArea(child: Column(mainAxisSize: MainAxisSize.min, children: [
        ListTile(leading: const Icon(Icons.photo_camera_outlined, color: AppColors.primary),
          title: const Text('拍照识别'),
          onTap: () { Navigator.pop(ctx); _pick(ImageSource.camera); }),
        ListTile(leading: const Icon(Icons.photo_library_outlined, color: AppColors.secondary),
          title: const Text('从相册选择'),
          onTap: () { Navigator.pop(ctx); _pick(ImageSource.gallery); }),
      ])),
    );
  }

  Widget _reportCard() {
    final disease = (_result!['disease'] as Map?)?.cast<String, dynamic>() ?? {};
    final label = '${_result!['resultLabel'] ?? disease['diseaseName'] ?? '疑似病害'}';
    final conf = ((_result!['confidence'] as num?)?.toDouble() ?? 0) * 100;
    final prevention = '${disease['prevention'] ?? '清除病叶，加强田间通风'}';
    final medicine = '${disease['medicineAdvice'] ?? ''}';
    final interval = disease['safeInterval'] ?? disease['safeIntervalDays'];

    return Container(
      decoration: BoxDecoration(
        color: AppColors.surface,
        borderRadius: BorderRadius.circular(R.md),
        border: Border.all(color: AppColors.primary, width: 1.5),
      ),
      padding: const EdgeInsets.all(16),
      child: Column(
        crossAxisAlignment: CrossAxisAlignment.start,
        children: [
          Row(children: [
            const Icon(Icons.verified, color: AppColors.primary, size: 18),
            const SizedBox(width: 6),
            const Text('智能植保诊断报告',
                style: TextStyle(fontSize: 14, fontWeight: FontWeight.w700, color: AppColors.primary)),
            const Spacer(),
            const StatusChip('VERIFIED', color: AppColors.primary),
          ]),
          const SizedBox(height: 12),
          Container(
            padding: const EdgeInsets.symmetric(horizontal: 10, vertical: 8),
            decoration: BoxDecoration(
              color: AppColors.primaryContainer.withValues(alpha: 0.10),
              borderRadius: BorderRadius.circular(R.sm),
            ),
            child: Row(children: [
              Expanded(child: Text(label,
                  style: const TextStyle(fontSize: 16, fontWeight: FontWeight.w700))),
              Text('${conf.toStringAsFixed(1)}%',
                  style: const TextStyle(fontSize: 16, fontWeight: FontWeight.w800, color: AppColors.primary)),
            ]),
          ),
          const SizedBox(height: 12),
          _line('防治建议', prevention),
          if (medicine.isNotEmpty) _line('推荐用药', medicine),
          if (interval != null) _line('安全间隔期', '$interval 天'),
        ],
      ),
    );
  }

  Widget _line(String k, String v) => Padding(
    padding: const EdgeInsets.only(bottom: 8),
    child: Column(crossAxisAlignment: CrossAxisAlignment.start, children: [
      Text(k, style: const TextStyle(fontSize: 12, color: AppColors.onSurfaceVariant)),
      const SizedBox(height: 2),
      Text(v, style: const TextStyle(fontSize: 14, height: 1.5)),
    ]),
  );
}
```

**不新增接口**。复用：
- `POST /agri/disease/detect`（已有，multipart image）

> Codex 确认 `record.create` 接受 `recordType / cropType / content / recordDate` 字段，且 recordDate 支持未来日期（应该支持，DateTime 字段）。

### 5. 农事记录列表展示未来「复查」待办
