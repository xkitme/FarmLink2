## 1. 问题

登录页处于未登录态时，`VoiceWakeState.init()`（AppBootstrap 启动装配）无条件
`GET /api/v1/ai/assistant/config`——该端点 `requireAuth`，后端正确回 401。
这不是断连，但会在浏览器 Network / console 产生一次无意义的 401 噪音。

## 2. 改动（Flutter lane，全部在 116x-60pct / 116h-A 白名单内）

| 文件 | 改动 |
|---|---|
| `app/lib/core/voice_wake.dart` | `init()` 不再发起 `/ai/assistant/config`（只恢复本地开关）；新增 `refreshWakeWordsIfAuthenticated()`（未登录直接返回零请求）；401/离线静默保留默认词；`resetToDefaults()` 供登出清词；实例注册表 + 静态 `notifySessionEstablished/notifySessionCleared`（会话事件广播，避免 main.dart 装配改动） |
| `app/lib/core/auth_state.dart` | `init()` 恢复登录态、`_save()`（登录/注册成功）后广播 `VoiceWakeState.notifySessionEstablished()`；`_clearLocalSession()`（登出/会话失效）广播 `notifySessionCleared()` |
| `app/test/voice_wake_401_test.dart` | 新增 6 测试：未登录 init 零请求 / 登录后刷新到远端词 / 401 保持默认词 / 未登录广播零请求 / logout 清回默认 / AuthState 登录+登出集成闭环 |

## 3. 行为契约

- 默认唤醒词恒为 `['你好小田']`（`defaultWakeWords` 不变）；
- 未登录：不请求 `/ai/assistant/config`；登录成功/冷启动恢复会话后请求一次；
- 请求失败（含 401）静默保留当前词，不打印错误；
- 登出/会话失效后清回默认词，不残留上一会话远端配置；
- 后端路由认证语义零改动：`/ai/assistant/config` 继续 `requireAuth`。
