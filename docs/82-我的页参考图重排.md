# 分段 82 — 「我的」页按品牌侧参考图重排版式

> 用户提供一张品牌 App（塔斯汀「中国汉堡」会员中心）截图，要求「按照这个图片重新设计『我的』页面，保留相关元素」。
> 本段只动 `profile_page.dart` 的**版式**，不改数据来源、同步逻辑、路由与后端。

## 一、目标

- 把参考图的**信息架构**搬到「我的」页：渐变 hero（头像+成长值+身份徽标）→ 叠压式数据概览卡 → 两张大入口卡 → 图标宫格菜单。
- **保留相关元素**：原有的个人身份、4 项数据概览、数据同步卡、我的事务入口、退出登录，全部留存，仅换表达方式。
- 用 InkFlow 既有设计语言落地参考图（**不照搬**其暖粉色/大圆角胶囊）：主绿 `heroGradient`、方角 `R.sm/R.md`、扁平描边盒 —— 对齐用户「利落方正」偏好。

## 二、背景

旧「我的」页是「白底身份盒 + 四宫格数字 + 竖排 ListTile 菜单」。参考图的版式更有层次：彩色 hero 压住一张半悬浮的数据卡，下面是双入口大卡 + 图标宫格。把这套结构对到 InkFlow 自己的内容上，观感更接近成熟 C 端会员中心，又不丢任何现有能力。

## 三、改动

文件：`app/lib/pages/profile/profile_page.dart`（整页 build 区重写，state/`_load`/`_autoSyncSilently` 逻辑原样保留）

| 参考图元素 | InkFlow 落地 |
|---|---|
| 暖色渐变 hero + 圆头像 + 成长值 + 水印 | 绿 `AppColors.heroGradient` hero；白环圆头像；`displayName`；成长值 `距下一等级还差 N 成长值`（由 `user.points` 推算：`nextLevelAt=((points~/100)+1)*100`，`remaining=nextLevelAt-points`）；角色/村庄半透明白徽标；右侧 `Icons.agriculture` 淡水印；整块点按 → `/profile/settings/account` |
| 4 项数据卡（优惠券/积分/余额/勋章） | 4 项概览卡（地块/农事/订单/AI，取自 `/data/dashboard` 的 `cards`），每项可点跳对应板块；用 `Transform.translate(0,-24)` 叠压在 hero 底缘 |
| 我的订单 / 团购兑换 双入口卡 | 我的订单(`/market`) / 我的发布(`/publish`) 双入口卡，左侧着色图标方块（主绿/黛青）+ 标题 + 副标 |
| —（参考图无） | **保留**数据同步卡：原 `_syncPanel` 逻辑不动，圆角统一 `R.md` |
| 图标宫格菜单（4 列，含 Hot 角标） | 我的事务 4 列 `GridView.count` 宫格：农事记录/灾情记录/政策申请/数据看板/消息通知/农机服务/适老模式(带「新」角标)/设置 |
| 底部 TabBar | 不动（由 `ShellPage` 提供） |

实现要点：

- 概览卡叠压用 `Transform.translate(offset: Offset(0,-24))`；hero 底 padding 留 40 以免被压住头像/文字；译后留下的 ~24 视觉间隙顶替了原本的卡间距，不另加 `SizedBox`。
- 宫格用 `GridView.count(shrinkWrap:true, physics:NeverScrollableScrollPhysics())` 嵌进 `ListView`，`childAspectRatio:0.92`。
- 「新」角标用 `Stack(clipBehavior:Clip.none)` + `Positioned(right:-6,top:-6)` 贴在图标方块右上。
- 颜色仅用既有 token（`primary/secondary/primaryContainer/error/heroGradient`），无新增色值。

## 四、契约

- 数据来源不变：`GET /user/profile`、`GET /data/dashboard`、`GET /data/sync/status` + 本地 `OfflineSyncQueue`。
- 路由不变：所有入口指向既有路由（`/market /publish /agri /disaster /policy/service /data /messages /machinery/service /profile/settings /profile/settings/elder /profile/settings/account`）。
- 无后端改动、无新增路由。

## 六、不在范围内

- 不改数据接口 / 不新增路由 / 不改 `ShellPage` 底栏。
- 不引入新色值或新组件库。
- 成长值「等级体系」仅是 points 的展示推算，不接后端等级表（后端暂无该字段）。
