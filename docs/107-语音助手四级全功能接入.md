# 107 · 语音助手「四级全功能接入」（直接答 / 全局搜索 / 页面内动作 / 导航全覆盖）

## 目标
用户拍板「所有功能接入语音助手」做满四级：
1. **语音 AI 问答（直接答）**——知识性/农技/政策问题口语化直接回答，不强行跳页。
2. **语音全局搜索**——说「搜索 XX」即进搜索页并立刻检索。
3. **页面内动作真执行**——不只导航，能真触发后端操作。
4. **导航全覆盖**——所有功能页/功能点都能由语音打开。

## 背景 / 现状盘点
- **L4 导航本就基本到位**：后端 `ROUTE_CATALOG`（35 页）+ `ROUTE_FEATURES`（69 功能点别名）+ 前端 `_routePaths` 三处对齐；`buildUserPrompt` 把 `availableRoutes`（带 features）注入**用户提示词**，与系统提示词无关，所以功能点导航一直能用。
- **L3 已有市集事务闭环**：`show_products/open_product/show_order_confirm/create_order/mock_pay` 是真下单真支付。
- **缺口**：L2 只有 `open_page search`（开空框，不检索）；L1 提示词偏自动化、从不引导直接答；L3 除市集外无其它页面动作。

## 改动
### 后端（`assistant.service.js`）
- `ALLOWED_COMMANDS` 新增 `search`、`toggle_linkage`。
- `sanitizeCommand`：
  - `search` → `{keyword}`（取 keyword/query/text，≤50 字，空则丢弃）。
  - `toggle_linkage` → `{ruleName(≤40), enabled:boolean}`；按规则名透传，由 App 端解析到真实规则 id（不在后端耦合规则表）。

### 后端提示词（`assistant-config.service.js` → `DEFAULT_SYSTEM_PROMPT`）
- 命令清单加 `search {keyword}`、`toggle_linkage {ruleName, enabled}`（ruleName 给出 5 条可控规则**原文名**：墒情自动滴灌 / 虫情活跃·植保预警 / 棚室高温通风 / 低温霜冻保温 / 水位过高排涝）。
- 新增规则 8（知识性问题直接答、≤3 句、可再 open_page 引导）、规则 9（检索意图用 search、keyword 去动词只留词）、规则 10（启停联动用 toggle_linkage）。

### 前端（`voice_assistant_layer.dart`）
- `_executeCommand` 加 `search`（`context.go('/search?q=<encode>')`）与 `toggle_linkage`（调 `_toggleLinkage`）。
- `_toggleLinkage`：先 `go('/iot')` → `GET /iot/linkage/rules` → `_resolveLinkageRule` 名称解析 → `POST /iot/linkage/rules/:id/toggle` → 回「已启用/已停用…」。
- `_resolveLinkageRule`：用 `_normForEcho`（去标点空白）后强匹配（互含）优先，否则取字重叠率最高且 ≥0.6 的一条——容忍同音/空格差异（DB「虫情活跃 · 植保预警」↔ 模型「虫情活跃·植保预警」）。

### 前端搜索页（`search_page.dart` + `router.dart`）
- `SearchPage` 加 `initialQuery`；带词进入即填充并 `addPostFrameCallback` 自动检索、不抢焦点弹键盘。
- `/search` 路由读 `?q=` 透传给 `initialQuery`。

## ⚠️ 关键坑：DB 存了**陈旧 systemPrompt** 盖掉了 DEFAULT
- `loadAssistantConfig` 逻辑：`systemPrompt = 库里存的 || DEFAULT_SYSTEM_PROMPT`。本机 DB 的 `SiteSetting:ai_assistant_config` 存了一份**老 FarmLink 版**提示词（只 8 个 routeKey、无 features、无规则 6/7），改 DEFAULT 根本不生效。
- 复测发现 L4 仍能用，是因为 `availableRoutes` 走用户提示词；但新 `search/toggle_linkage` 命令只声明在系统提示词里 → 模型没学到 → 不输出。
- **修法**：把库里 `systemPrompt` 清空（`=''`）→ 回落到代码 DEFAULT。这是 doc103 作者本意（他改 DEFAULT 期望生效）。**seeds 不写这个键**，所以全新比赛机本就用 DEFAULT、不受影响；只有本机这份历史 admin 存值是脏的。
- 教训：后续要让助手提示词改动生效，确认 DB 没存自定义 prompt，否则要同步清/改库。

## 契约
- 新增命令 `search`、`toggle_linkage`（白名单 + sanitizer）。命令返回值的 `reply` 仍是前端内部用（见 doc106）。
- `/search?q=` 查询参数为新增可选入口；无 q 时行为不变（自动聚焦搜索框）。
