# 60 - 全局卡片详情页第一批（issue #16）

> 承接 GitHub issue #16「所有卡片（除登录页）全部改成单独的页面，类似详情页」。
> 本批只处理“纯展示型详情 sheet”，不处理表单、确认弹窗、图片来源选择、购物/预约等强交互弹层。

## 目标

把 App 中一批只用于展示结果或详情的底部弹层迁移为独立详情页，先建立可复用页面基础设施。

## 改动

- 新增 `app/lib/pages/common/info_detail_page.dart`
  - `InfoDetailData` / `InfoSection` 作为路由传参数据。
  - `InfoDetailPage` 负责纯文本、分段、列表与图片展示。
- 更新 `app/lib/core/router.dart`
  - 新增 `/detail/info` 路由。
  - 对缺失 `state.extra` 的 Web 刷新/外部访问做兜底，避免强转崩溃。
- 迁移以下页面中的纯展示型 `_infoSheet` / `_sheet`：
  - `app/lib/pages/agri/agri_page.dart`
  - `app/lib/pages/disaster/disaster_page.dart`
  - `app/lib/pages/market/market_service_page.dart`
  - `app/lib/pages/policy/policy_service_page.dart`
  - `app/lib/pages/life/life_page.dart`

## 不在本批范围

- 不关闭 issue #16。
- 不改表单输入 sheet、图片来源选择 sheet、确认弹窗、购物车、预约、发布等操作型弹层。
- 不做国风 UI 或设计体系大重构。
- 不改后端接口、数据结构或种子数据。

## 验收

- `cd app && C:\dev\flutter\bin\flutter.bat analyze lib`
  - 结果：`No issues found! (ran in 1.3s)`
- `cd app && C:\dev\flutter\bin\flutter.bat build web --debug`
  - 结果：构建通过，生成 `app/build/web/main.dart.js`
- 启动 `node app/serve_web.mjs` 后检查：
  - `GET http://localhost:5000/detail/info` 返回 `200`
  - `GET http://localhost:5000/main.dart.js` 返回 `200`
  - `GET http://localhost:5000/manifest.json` 返回 `200`

## 实施备注

本批代码由 DeepSeek V4 Pro 先实现，Codex 审查后删除了越界生成的国风 UI 计划文档，并补了 `/detail/info` 缺失 `state.extra` 时的安全兜底与详情页返回 fallback。
