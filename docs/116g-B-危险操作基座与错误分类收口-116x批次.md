## 3. 行为契约

- 只有 `unauthenticated` 清会话并跳登录；409/422 与 403/CSRF/429/5xx/断网一样**不清会话、不登出**；
- 危险操作（删除）在 config 未就绪 / 错误态 / 无权限 / busy 时 disabled 且有 Tooltip 原因；
- 写请求仍 `credentials:include` + `X-CSRF-Token`；绝不自动重试（既有契约不变）；
- 系统维护字段永不进入提交体（前端最后一层防线；后端 resource.policy 同步收口）。
