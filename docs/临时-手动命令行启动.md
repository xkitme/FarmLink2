# 临时文档：手动命令行启动

> 本文只记录不用 `scripts/start-local.ps1` 的手动启动命令。
> 目标：后端、移动端 Web 静态服务、管理台都用命令行手动启动；静态服务使用 Node.js，不使用 Python。

## 一、启动后端

新开一个 PowerShell 窗口：

```powershell
cd D:\dgitc_project\InkFlow\backend
$env:PORT=8000
$env:FARMLINK_BACKEND_PORT=8000
node src/server.js
```

后端地址：

```text
http://localhost:8000/api/v1
```

## 二、构建移动端 Web

新开第二个 PowerShell 窗口：

```powershell
cd D:\dgitc_project\InkFlow\app
C:\dev\flutter\bin\flutter.bat build web --pwa-strategy=none --dart-define=FARMLINK_API_BASE_URL=http://localhost:8000
```

如果只是重新启动，且 `app/build/web` 已经存在，可以跳过这一步。

## 三、用 Node.js 启动移动端 Web

继续在第二个 PowerShell 窗口运行：

```powershell
npx --yes http-server build/web -p 5000 -a 0.0.0.0 -c-1
```

移动端地址：

```text
http://localhost:5000
```

说明：

- 这里的 `http-server` 是 Node.js 静态文件服务器。
- `-c-1` 表示关闭缓存，方便刷新后看到最新构建。
- 不需要 `python -m http.server`。

## 四、启动管理台

需要管理台时，新开第三个 PowerShell 窗口：

```powershell
cd D:\dgitc_project\InkFlow\backend\admin
npm run dev -- --host 0.0.0.0 --port 5173
```

管理台地址：

```text
http://localhost:5173/admin/
```

## 七、端口被占用时

查看端口占用：

```powershell
Get-NetTCPConnection -LocalPort 8000,5000,5173 -State Listen
```

结束指定进程：

```powershell
Stop-Process -Id <PID> -Force
```
