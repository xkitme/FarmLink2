# 分段 45a — 数据剧本化

> 返回：[45-招牌场景与产品重构计划.md](45-招牌场景与产品重构计划.md)
> 所属 lane：Lane C · 内容故事化（C1）。

## 一、目标

把初始化数据从“功能占位数据”改成“松华村三位主角的一年”，让后续拍照闭环、村级驾驶舱和月度经营报告都有同一套可串联的数据基础。

## 二、背景

分段 45 的根因诊断指出：当前项目功能多，但缺少能被复述的主角故事。S1 第一件事先补数据剧本，让张大叔、李大姐、王村委贯穿农事、集市、灾情、政策和数据看板。

## 三、改动清单

### `backend/seeds/index.js`

- 用户主角改为：
  - `farmer / 张大叔 / 张大山`
  - `bigfarmer / 李大姐 / 李桂兰`
  - `village / 王村委 / 王建华`
- 补齐三位主角积分流水，形成登录后可见的人物状态。
- 商品数据改为可溯源产品：
  - 张大叔松华香米
  - 张大叔后山红心柑橘
  - 李大姐阳光番茄
  - 李大姐有机蔬菜礼盒
- 新增订单与溯源记录，让集市与溯源模块有真实业务链路。
- 新增 5 块地与 19 条全年农事记录，覆盖播种、插秧、施肥、打药、巡田、采收、统计上报。
- 新增 AI 识别、产量预测、灾情上报、保险理赔、政策申请、年度报告、统计上报、同步日志、AI 问答记录。
- 修正与人物设定冲突的旧姓名和农场名称。

## 四、接口契约

本段不新增接口，只增强现有接口返回的数据密度。

已有接口验收重点：

- `POST /api/v1/auth/login`
- `GET /api/v1/agri/record/list`
- `GET /api/v1/data/dashboard`
- `GET /api/v1/market/product/list`
- `GET /api/v1/market/trace/{code}`
- `GET /api/v1/policy/subsidy/list`
- `GET /api/v1/disaster/report/list`
