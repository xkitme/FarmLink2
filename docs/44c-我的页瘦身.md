# 分段 44c — 「我的」页瘦身

> 归属分段 45 的 S0 清账。目标是让「我的」页从板块入口重复页，回归个人事务中心。

## 一、目标

- 删除与主页核心服务重复的板块入口。
- 保留个人身份、概览、数据同步能力。
- 将常用服务改为“我的事务”，突出订单、发布、农事、灾情、政策申请等个人路径。

## 二、实施备注

文件：`app/lib/pages/profile/profile_page.dart`

处理：

- 小节标题从“常用服务”改为“我的事务”。
- 移除重复板块入口：
  - 数据看板
  - 乡村集市
  - 惠农政策
  - 农机共享
- 新增 / 保留个人事务入口：
  - 我的订单 → `/market`
  - 我的发布 → `/publish`
  - 农事记录 → `/agri`
  - 灾情记录 → `/disaster`
  - 政策申请 → `/policy/service`
  - 消息通知 → `/messages`
  - 适老模式 / 设置

> 说明：当前仓库还没有独立的“我的订单 / 农事记录详情 / 灾情记录详情”子路由，因此本段使用已有业务页作为落点，仅调整入口语义与页面职责。

## 三、不在范围内

- 不新增独立订单页。
- 不新增路由。
- 不改主页、底栏、ShellPage。
- 不改后端接口。
