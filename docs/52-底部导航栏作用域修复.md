# 分段 52 — 底部导航栏作用域修复

> 工作单（Codex 实施）。用户反馈：底部导航栏只该在 5 个一级 tab 出现，
> **详情页 / 二级页 / 弹出卡片（modal sheet）** 一律不展示。
> 完成后跑 `flutter analyze lib` + `flutter build web`，commit 中文。

## 一、问题描述

当前 `app/lib/pages/home/shell_page.dart` 的 `ShellPage.build()` **无条件**渲染
`bottomNavigationBar`，而 `app/lib/core/router.dart` 的 `ShellRoute` 把所有登录后
路由（包括详情页）都挂在同一个 shell 下，所以：

- `/disaster`、`/agri`、`/market`、`/machinery`、`/policy`、`/life`、`/data` 这些**板块详情页**底部都顶着导航栏 → 视觉重；
- `/machinery/service`、`/policy/service`、`/market/service`、`/data/service` 这些**服务子页**也是；
- `/ai/chat/new`、`/ai/chat/:id` **AI 聊天详情**底部也是；
- `/profile/settings/*` 所有**设置二级页**也是；
- `showModalBottomSheet` 弹出的卡片（气象上报、领取救助、SOS、信息卡等）目前用的是**最近的 Navigator（shell navigator）**，sheet 浮在 ShellPage 的 body 之上，**底栏依旧露出来** → 用户希望卡片是「全屏覆盖」的层级，不要看到底栏。

## 二、Lane I · 一级 tab 才显示底栏（路由层）

### I1 · ShellPage 按精确路径开关底栏

`app/lib/pages/home/shell_page.dart`：

把 `_index(loc)` 改造或新增一个 `_isTopLevelTab(loc)`，只在**精确等于** 5 个 tab 路径时返回 true：

```dart
static const _tabPaths = {'/home', '/ai', '/publish', '/messages', '/profile'};

bool _isTopLevelTab(String loc) => _tabPaths.contains(loc);

int _index(String loc) {
  for (var i = 0; i < _tabs.length; i++) {
    if (loc == _tabs[i].path) return i;
  }
  return -1; // 详情页不高亮任一 tab
}
```

`build()` 改为：

```dart
@override
Widget build(BuildContext context) {
  final loc = GoRouterState.of(context).uri.path;
  final showBar = _isTopLevelTab(loc);
  final idx = _index(loc);
  return Scaffold(
    body: widget.child,
    bottomNavigationBar: showBar ? _navBar(idx) : null,
  );
}
```

把现有 `bottomNavigationBar` 那段 Container/SafeArea/Row 抽成私有方法 `_navBar(int idx)`，签名 `Widget _navBar(int idx)`，内容不变。

**重要边界**：
- `/ai/chat/new`、`/ai/chat/:id` 属于详情，不显示底栏（与 `/ai` 区分，正是用 `==` 而不是 `startsWith` 的原因）。
- `/profile/settings`、`/profile/settings/account` 等所有设置子页同理，不显示。
- 板块详情（`/disaster`、`/agri`、`/market`、`/machinery`、`/policy`、`/life`、`/data` 及 `/*/service`）一律不显示。

### I2 · 详情页面 SafeArea 底部边距确认

底栏拿掉后，详情页底部内容应直接顶到屏幕底（系统手势区由 SafeArea 处理）。
通常用 `ListView` / `SingleChildScrollView` 的页面无需改动；
但**带固定 FAB 或浮动按钮**的页面（如 `disaster_page.dart` 的「我要上报」CTA、`publish_page.dart`）要确认按钮没被系统手势条遮挡。

实施时打开下列页面跑 `flutter run -d chrome`（或 web 预览）肉眼确认：

- `/disaster`、`/agri`、`/market`、`/machinery`、`/data`
- `/ai/chat/new`
- `/profile/settings`

若有按钮被遮，给该页 Scaffold 加 `bottomNavigationBar: SafeArea(top:false, child: SizedBox.shrink())` 或在按钮外包 `SafeArea`（**最少改动**为准）。

## 三、Lane J · 弹层用 root navigator（让底栏被遮）

### J1 · 全项目搜索 showModalBottomSheet

```
grep -rn "showModalBottomSheet" app/lib
```

预期命中 13 个文件（disaster / publish / market / ai / life / about / data / messages / agri / policy / policy_service / machinery_service / market_service）。

### J2 · 每个调用点加 `useRootNavigator: true`

默认 `useRootNavigator: false`，sheet 推到最近的 ShellRoute 的 Navigator，**底栏不会被覆盖**。
改成 `true` 后 sheet 推到根 Navigator（在 ShellPage 之上），**整块屏幕（含底栏）都被遮**，符合用户预期。

示例：

```dart
showModalBottomSheet(
  context: context,
  isScrollControlled: true,
  useRootNavigator: true,           // ← 新增
  backgroundColor: Colors.transparent,
  builder: (_) => _ReportSheet(...),
);
```

> ⚠️ 注意：sheet 内部如果用了 `Navigator.of(context).pop()` 关闭，确认它拿到的是
> sheet 自己那层 navigator（`context` 来自 `builder` 内）—— `useRootNavigator: true`
> 不影响 pop 行为，因为 sheet 路由本身就压在 root 上。

### J3 · 顺手统一弹层样式（可选，0 行新功能）

如果发现各处 sheet 的 `shape` / `backgroundColor` 不一致，本次**不动**——
只补 `useRootNavigator: true`，避免把范围铺开。
