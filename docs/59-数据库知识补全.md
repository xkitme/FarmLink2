## 一、目标（一句话）

把农技/政策/灾害/生活知识种子从「能跑」补到「够用」，使 `searchLocalKnowledge` 对常见农户问题能检索到实质片段、图像识别有足够病害库支撑、首页行情/政策不空。

## 二、背景：知识架构与现状（已核实）

RAG（`backend/src/modules/ai/services/rag.service.js`）按场景检索：
- **AGRI** → `diseaseKnowledge` + `pesticideInfo` + `farmCalendar`
- **POLICY / LEGAL** → `policyChunk`（由 `policy.content` 按句切片）
- **DISASTER** → `disasterRefs`（灾害相关表）
- **LIFE / EDU / LOAN** → `lifeRefs`（生活相关表）
- **GENERAL** → 上述混合

**现有种子条数（`backend/seeds/index.js`，偏薄）**：
| 表 | 现有 | 影响 |
|---|---|---|
| `diseaseKnowledge` | **8** | AGRI 病虫害检索 + 图像识别兜底库（`fallbackImageResult` 从此表随机取），8 条 → 识图老命中同几个、病害问答检索不到 |
| `pesticideInfo` | **9** | 用药/剂量检索 |
| `farmCalendar` | **12** | 农事历/节气农事检索 |
| `policy`(+chunk) | ~充实 | 政策问答（已较好，按需补类目） |
| `marketPrice` | 8 品×7 天 | 首页本地行情、集市行情 |

## 三、补全范围与目标（按优先级）

> 内容要**真实、准确、可执行**（真农业知识，不许编造农药登记证号/剂量到误导程度；剂量给区间或"按标签"）。中文，字段对齐 schema。

### P0 · `diseaseKnowledge`：8 → **≥ 50**
字段：`diseaseName, cropType, category(虫害/病害/缺素), symptoms, cause, prevention, medicineAdvice, modelLabel(AI标签), coverImage?`
覆盖主粮 + 经作 + 蔬菜 + 果树的高频病虫害，建议每作物 4~8 条：
- 水稻：稻瘟病、纹枯病、稻飞虱、二化螟、稻曲病、白叶枯…
- 玉米：大斑病、小斑病、玉米螟、粘虫、蚜虫…
- 小麦：条锈病、白粉病、赤霉病、蚜虫…
- 蔬菜：番茄晚疫/早疫/病毒病/脐腐、黄瓜霜霉/白粉、辣椒炭疽、白菜软腐、根结线虫、蚜虫粉虱…
- 果树：柑橘红蜘蛛/木虱/溃疡/黄龙病、苹果腐烂/红蜘蛛、葡萄霜霉/白腐、桃蚜/疮痂…
- 缺素：缺氮/磷/钾/钙/硼/铁 各 1 条（症状 + 矫正）
`modelLabel` 给一个稳定英文/拼音标签（图像识别可对应），`prevention`/`medicineAdvice` 写到可执行（农业措施 + 药剂示例 + 安全间隔提示）。

### P0 · `pesticideInfo`：9 → **≥ 30**
字段：`name, regNo?, type(杀虫/杀菌/除草剂), targetPest, cropType, safeDosage, safeInterval, toxicity`
覆盖常用药：吡虫啉、啶虫脒、阿维菌素、螺螨酯、噻虫嗪、苯醚甲环唑、嘧菌酯、代森锰锌、烯酰吗啉、井冈霉素、三环唑、多菌灵、草甘膦、烟嘧磺隆…
`safeDosage` 写常规用量区间（如"每亩 X~Y 克兑水 30~45kg"），`safeInterval` 给天数，`regNo` 可留空或写示例占位（不强求真实证号）。

### P1 · `farmCalendar`：12 → **≥ 36**
字段：`solarTerm?, month(1~12), cropType, activity, description`
按 12 个月 / 24 节气 × 主要作物给农事（整地、播种、育苗、移栽、施肥、灌溉、病虫防治、收获、储藏），每月覆盖 3+ 条。

### P1 · `marketPrice`：8 品 → **15~20 品**
在现有 `products` 数组加品类（粮油：稻谷/小麦/油菜；蔬菜：辣椒/茄子/白菜/萝卜；水果：草莓/葡萄/苹果；畜禽：鸡蛋/肉鸡），保持「7 天 × 每品」生成逻辑不变。

### P2 · `policy`（+chunk）按类目补全
确认覆盖：种植补贴 / 农机补贴 / 金融信贷 / 教育 / 医疗养老 / 产业奖补 / 灾害救助。每类至少 2~3 条，`content` 写充实（会被自动切片成 chunk 供 RAG）。

### P2 · 灾害 / 生活知识表
按 `disasterRefs` / `lifeRefs` 实际查询的表（读 `rag.service.js` 确认表名与字段）各补到 ≥ 15 条，覆盖：旱涝/风雹/低温/病虫灾害应急；就业/医疗/养老/快递/缴费/培训。
