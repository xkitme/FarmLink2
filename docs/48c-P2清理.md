## G10 · server.js setDefaultEncoding 注释/删除

### 现状

`backend/src/server.js:5-13` 加了：

```js
// Windows 终端默认 GBK，强制 stdout/stderr UTF-8 以兼容中文日志
if (process.platform === 'win32') {
  try {
    process.stdout.setDefaultEncoding?.('utf8')
    process.stderr.setDefaultEncoding?.('utf8')
  } catch (_) {}
}
```

但 `setDefaultEncoding` 是 Writable 的 API，控制 String → Buffer 转换的默认编码，Node 默认已经 utf-8。Windows 控制台乱码源在控制台代码页（GBK 936），跟这段代码无关。真正的修复在 `start.bat` 的 `chcp 65001`。

### 改动

二选一：

#### 方案 A（推荐）· 删除这段，避免误导

直接删除 line 5-13 这块。

```js
// （删除）

async function checkOllama() { ... }
```

#### 方案 B · 改注释，标记为"无害但非真修复"

```js
// 注：Windows 控制台乱码的真正修复在 start.bat 的 chcp 65001。
// 此处保留 setDefaultEncoding 仅作对齐用途，对乱码无效。
if (process.platform === 'win32') {
  ...
}
```

**推荐方案 A**。如果删除后 `start.bat` 走 `chcp 65001` 已能正常显示中文（47a 验证过 OK），那这段代码冗余。

## 顺手清理（顺便扫掉）

### C1 · clearCache 死前缀

`app/lib/pages/profile/settings/settings_home_page.dart` 的 `_clearCache` 内：

```dart
final keys = sp.getKeys().where(
  (k) => k.startsWith('cache:') || k.startsWith('dashboard:') || k.startsWith('service:')
).toList();
```

`dashboard:` / `service:` 前缀**无任何 writer**。改为：

```dart
final keys = sp.getKeys().where((k) => k.startsWith('cache:')).toList();
```

### C2 · 负 id 约定文档化

`app/lib/pages/ai/ai_threads_page.dart` 内 `id = -annualReport.id` 这段加注释，避免后续重构破坏：

```dart
// 负数 id 用于区分 annualReport thread 与 qaRecord thread。
// onTap 时通过 kind == 'REPORT' 路由，不要直接用 id 跳 /ai/chat/:id。
final t = _Thread(
  id: -((r['id'] as num).toInt()),
  kind: 'REPORT',
  ...
);
```

如果 48a G3 把 thread 化做实，这块可以同步删除（annualReport 不再以负 id 混入 qaRecord 列表，可单独走一个区块展示）。

### C3 · ShellPage `_index` startsWith 加边界

`app/lib/pages/home/shell_page.dart:_index`：

```dart
int _index(String loc) {
  for (var i = 0; i < _tabs.length; i++) {
    final path = _tabs[i].path;
    if (loc == path || loc.startsWith('$path/')) return i;   // 加 '/' 边界
  }
  return 0;
}
```

避免未来 `/aimanage` 这种路径误匹配 `/ai` tab。

### C4 · scene 死代码 query 参数

`router.dart` 的 `/ai/chat/new` 接收 `?scene=` 但无调用方传。要么：

- **保留**（未来主页招牌画面 D2 工作单可能传），加注释
- 或先删除支持，等真正需要时再加

推荐保留 + 加注释：

```dart
GoRoute(
  path: '/ai/chat/new',
  // 保留 ?scene= 查询参数，未来主页招牌画面入口（D2）会传 scene=DISEASE / POLICY 等
  builder: (_, state) => AiChatPage(
    initialScene: state.uri.queryParameters['scene'] ?? 'GENERAL',
  ),

```
