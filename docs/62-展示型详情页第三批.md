# 62 - 展示型详情页第三批（issue #16）

> 承接 GitHub issue #16「所有卡片（除登录页）全部改成单独的页面，类似详情页」。
> 本批继续处理明确展示型的卡片详情，不迁移表单、确认弹窗、图片来源、同步日志等操作型弹层。

## 目标

把消息详情、政策详情、年度农事报告详情从底部弹层迁移到已有的 `/detail/info` 独立详情页。

## 改动

- 更新 `app/lib/pages/messages/messages_page.dart`
  - `_openMessage` 保留未读标记与 `_reload` 刷新逻辑。
  - 消息详情从 `showModalBottomSheet` 改为 `context.push('/detail/info', extra: InfoDetailData(...))`。
  - 详情保留消息标题、正文、消息类型、创建时间。
- 更新 `app/lib/pages/policy/policy_page.dart`
  - `_openDetail` 保留政策详情接口读取与失败 toast。
  - 政策详情从 `DraggableScrollableSheet` 改为 `/detail/info`。
  - 详情保留分类、标题、正文；`applyGuide` 不为空时展示为「申请指引」段落。
- 更新 `app/lib/pages/data/data_service_page.dart`
  - 年度农事报告详情从 `showModalBottomSheet` 改为 `/detail/info`。
  - 生成年度报告后仍会立即打开详情。
  - 详情保留年份、成本、摘要、报告正文。

## 不在本批范围

- 不关闭 issue #16。
- 不迁移年份选择、统计上报、同步日志、确认弹窗、图片来源选择等操作型弹层。
- 不改 `/detail/info` 路由、通用详情页组件、后端接口或数据结构。
