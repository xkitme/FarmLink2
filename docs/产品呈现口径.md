# 产品呈现口径

> 田园通对外定位为一套**在线 SaaS 数字乡村平台**。
> 离线只是底层运行方式的一种实现细节，不构成产品卖点，**不在用户可见层面强调**。
> 本文件统一文案口径，所有界面、提示、对外文档须按此撰写。

## 一、原则

1. 把项目当成一个**正式在线服务**做：用户感知到的是「云端平台」。
2. 离线能力是内部技术实现，写在 README「技术架构」一节即可，**不向用户暴露**。
3. 任何「离线 / 断网 / 本地兜底 / 单机 / 本地模型」类术语，在 UI、Toast、空状态、引导页、
   宣传图、应用商店介绍、产品帮助里**一律禁用**。
4. 错误统一以「服务侧」口径呈现，不要把责任归到「网络」或「本地」。

## 二、文案对照表

| 场景 | ❌ 旧（突出离线） | ✅ 新（在线 SaaS 口径） |
|---|---|---|
| 错误码 60002 | 已切换至离线兜底 | 服务暂时不可用，请稍后重试 |
| 同步队列入队 | 已存本地，联网后回放 | 已加入待发送队列，将自动重传 |
| 同步队列重传成功 | 离线数据已上传 | 数据已同步 |
| AI 离线降级 | 本地知识库兜底 | 正在处理中 |
| AI 在线 vs 离线 chip | 「模型在线 / 离线兜底」 | 不展示状态；或统一显示「AI 服务」 |
| 缓存兜底 banner | 当前展示本地缓存 | 不显示 banner，直接展示数据 |
| 启动页副标题 | 离线优先 · 本地 AI | 智能农业云平台 |
| 引导页 | 断网照常用 / 本地 AI | 一站式智能农业服务 / AI 助手随身 |
| 应用介绍 | 完整可独立部署 | 完整数字乡村解决方案 |
| 数据看板 hero | 数据来自本机 SQLite | 数据来自平台 |
| 同步状态卡 | 离线同步状态 | 数据同步状态 |

## 三、可保留的术语

- 「数据同步」「同步队列」「待发送 / 已发送」—— 中性词，可用
- 「云端」「平台」「服务」—— 推荐
- 「AI 助手」「AI 识别」「AI 问答」—— 推荐，**不要带「本地」前缀**
- 「实时」「在线」—— 可用，但不要强调反义

## 四、内部 vs 对外

| 层 | 是否可提离线 |
|---|---|
| 用户 UI / Toast / 空状态 / 引导页 | ❌ 禁止 |
| 应用商店介绍 / 宣传材料 | ❌ 禁止 |
| 用户帮助中心 / FAQ | ❌ 禁止（避免主动暴露） |
| README「项目简介 / 核心特点」 | ⚠️ 弱化，可写「弹性部署」「可在内网/外网均可运行」 |
| README「技术架构」一节 | ✅ 可写（技术实现细节） |
| docs/ 内部分段文档 | ✅ 可写（开发记录） |
| 后端日志 / 错误详情 | ✅ 可写（运维诊断） |

## 五、执行清单

后续凡涉及到以下文件改动，须按本口径校对一次文案：

- `app/lib/pages/splash/splash_page.dart` 启动页 / 引导页
- `app/lib/pages/**` 所有用户可见 Toast、空状态、错误提示
- `app/lib/widgets/common.dart` 通用提示组件默认文案
- `app/lib/core/api_client.dart` 错误码 60002 的对外提示
- `app/lib/core/offline_sync_queue.dart` 队列入队 / 同步成功提示
- `backend/src/utils/response.js` 错误码 60002 的 `msg`
- `README.md` 「项目简介」「核心特点」段（保留「技术架构」中的离线描述）
- 管理面板登录页、仪表盘空状态文案

## 六、生效

自分段 31 起，所有新增 / 修改的页面与文案默认按本口径执行。
存量页面在后续板块联调（分段 31+）时按板块批量校对，不需要单独开分段。
