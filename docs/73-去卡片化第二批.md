## 通用规则（与 doc 71 相同）

### A. 展示型 AppCard → 扁平容器
- 在**每个文件内**建一个私有 helper（参考 doc 71 在 agri_page 建的 `_flatBox`）：
  白底 + `Border.all(color: AppColors.outlineVariant, width: 1)` + `BorderRadius.circular(R.sm)` + **无 boxShadow**，
  可选 `onTap` 用 `InkWell` 包裹。把**展示型** `AppCard(...)`（点进去只看详情、无就地操作）换成它。
- 同质长列表可改「白底 + 1px `Divider` 分隔行」，按该 section 现有结构选更自然的。
- **不要删 `AppCard` 类**（别处仍用）；只是这些页不再用它包展示型项。

### B. 展示型弹层 → 跳详情页
- 纯展示型 `showModalBottomSheet` / `_sheet` / `_infoSheet` 改为
  `context.push('/detail/info', extra: InfoDetailData(title:..., body/sections:..., actionLabel?, onAction?))`
  （路由已存在，复用，**别新增路由**）。
- **操作型**弹层（表单 / 多按钮 / 就地编辑 / 预约 / 缴费确认 / 设置开关）本轮**保留不动**。拿不准的记进备注，别硬改。

### C. 口径
- 守 `docs/产品呈现口径.md`：在线 SaaS，**禁**「离线 / 断网 / 本地兜底」等词。业务逻辑、数据加载、跳转语义不变，只改呈现层。
