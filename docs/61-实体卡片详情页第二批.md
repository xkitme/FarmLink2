# 61 - 实体卡片详情页第二批（issue #16）

> 承接 GitHub issue #16「所有卡片（除登录页）全部改成单独的页面，类似详情页」。
> 本批处理带业务动作的实体卡片，不扩大到消息、订单或购物流程。

## 目标

把农机列表卡片、乡村发布动态卡片从底部详情 sheet 迁移为独立详情页，并保留原有业务动作。

## 改动

- 更新 `app/lib/core/router.dart`
  - 新增 `/machinery/detail` 路由。
  - 新增 `/publish/detail` 路由。
  - 对缺失 `state.extra` 的 Web 刷新/外部访问做兜底，避免路由强转崩溃。
- 更新 `app/lib/pages/machinery/machinery_page.dart`
  - 列表卡点击从直接打开预约 sheet 改为进入农机详情页。
  - 新增 `MachineDetailPage`，展示图片、名称、类型、价格、押金、评分、机主和距离。
  - 详情页保留「预约农机」按钮，并复用原 `_BookingSheet`。
- 更新 `app/lib/pages/publish/publish_page.dart`
  - 动态卡点击从底部详情 sheet 改为进入 `PostDetailPage`。
  - `PostDetailPage` 复用原响应/拨号逻辑；响应成功后 `context.pop(true)`，列表页收到结果后刷新。
  - 清理旧 `_PostDetailSheet` 死代码。

## 不在本批范围

- 不关闭 issue #16。
- 不处理消息详情、订单详情、购物车、图片来源选择、确认弹窗等其它操作型弹层。
- 不改后端接口、数据结构、种子数据或权限逻辑。
- 不做全局动效优化；本批只处理详情入口形态。
