## 执行内容

### 1. 清空旧项目
- 停止占用目录的 node / dart / java 进程
- 删除 `D:\dgitc_project\InkFlow` 下旧项目全部文件（保留 `.git`）

### 2. 建立 docs 进度体系
- `docs/进度总览.md` — 主进度索引（每次任务前必读）
- `docs/01-项目初始化.md` — 本分段详情

### 3. 后端骨架（Node.js + Express + Prisma + SQLite）
目录结构：
```
backend/
├── package.json          依赖与脚本
├── .env / .env.example   环境变量
├── .gitignore
├── prisma/schema.prisma  数据库 Schema（本段仅 User，全表见分段02）
└── src/
    ├── server.js         启动入口
    ├── app.js            Express 应用
    ├── config/index.js   配置
    ├── middleware/        中间件（错误处理、鉴权）
    ├── routes/            路由
    ├── controllers/       控制器
    ├── services/          业务服务
    └── utils/             工具（统一响应、traceId）
```

### 4. 核心基础设施
- 统一响应封装 `{ code, msg, data, timestamp, traceId }`
- 全局异常处理中间件
- JWT 鉴权中间件（requireAuth / requireRole / optionalAuth）
- 健康检查接口 `/health`
