## 11. 未完成项 / 风险

1. **Flutter Web UI 登录（浏览器 UA）不可用**：C2b Cookie 迁移后，浏览器 UA 登录走 HttpOnly Cookie 通路，后端登录响应不含 token/refreshToken；而 Flutter `auth_state._save` 强校验 token 非空，Web 预览 UI 登录会报「登录会话响应异常」(50001)。项目既定做法（docs 各批浏览器实测）为注入 farmer token 验证登录后页面；正式客户端 Android APK 走 Capacitor 原生 UA → Bearer 通路，登录正常。**如需在浏览器/评委 Web 演示中支持表单登录，需要后续工作单授权修复（如 Web 端识别 + 返回 token 或 _save 兼容 cookie 会话），本次未越界改动。**
2. **git fetch 网络失败**：本次对 github.com:443 的 `git fetch` 连续失败（Connection reset / timeout），已按工单停止条件停止 fetch；远端状态改用 gh API（api.github.com）实测确认（main hash、open PR=0）。push/PR 链路需网络恢复后验证。
