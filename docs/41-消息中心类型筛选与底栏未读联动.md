# 分段 41 — 消息中心类型筛选与底栏未读联动

> 在分段 40 完成数据同步可见性后，继续补齐移动端消息闭环：
> 消息中心支持类型筛选，底栏「消息」Tab 实时展示未读数量。

## 一、目标

- 消息中心可按「全部 / 未读 / 预警 / 政策 / 农事 / 系统」筛选。
- 消息卡片展示类型标签，避免用户只靠图标判断消息来源。
- 底栏「消息」Tab 显示未读角标；进入消息页、标记已读、全部已读后同步刷新。
- 后端通知列表补充 `type` 与 `isRead` 查询参数，便于管理台在线调试。

## 二、移动端实现

### 1. 新增通知未读共享状态

文件：`app/lib/core/notification_state.dart`

新增 `NotificationState.unread` 作为全局 `ValueNotifier<int>`：

- `refresh()` 调用 `/notification/unread` 获取未读数。
- `setUnread()` 给消息页主动同步底栏状态。
- 请求失败时保留上一次数字，避免底栏角标闪烁。
- 退出登录时由 `AuthState.logout()` 清零。

### 2. 底栏未读角标

文件：`app/lib/pages/home/shell_page.dart`

- `ShellPage` 从 `StatelessWidget` 改为 `StatefulWidget`。
- 首次进入 Shell 与路由变化时刷新未读数。
- `_NavItem` 增加 `badgeCount`，仅消息 Tab 展示红色角标。
- 角标固定在 34x28 图标区域内，避免数字变化导致底栏抖动。

### 3. 消息中心筛选

文件：`app/lib/pages/messages/messages_page.dart`

- 新增 `_MessageFilter` 配置，覆盖 6 个筛选项。
- 消息列表一次拉取最近 100 条，前端按类型和未读状态做即时筛选。
- 筛选条使用横向 `ChoiceChip`，显示当前分类数量。
- 卡片中新增 `StatusChip` 类型标签：预警 / 政策 / 农事 / 系统。
- 当前分类为空时展示独立空状态，不影响全部消息列表。
- 加载未读数后调用 `NotificationState.setUnread()`，标记已读后底栏立即更新。

## 三、后端与管理台调试

### 1. 通知列表查询增强

文件：`backend/src/modules/platform/notification.controller.js`

`GET /api/v1/notification/list` 新增查询参数：

| 参数 | 说明 |
|---|---|
| `type` | `ALERT` / `POLICY` / `FARM` / `SYSTEM`，不传或 `ALL` 表示全部 |
| `isRead` | `true` / `false`，不传表示全部 |

响应数据继续保留分页结构，并额外返回：

- `unread`：当前账号总未读数
- `typeCounts`：当前账号各类型消息数量

### 2. API 在线调试目录补充

文件：`backend/admin/src/apiCatalog.js`

在「系统与驾驶舱」组增加：

- 消息通知列表：`/notification/list?pageNum=1&pageSize=10&type=ALERT`
- 消息未读数：`/notification/unread`

方便管理台直接验证筛选和未读计数接口。
