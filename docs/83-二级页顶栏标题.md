# 83-二级页顶栏标题

> 本分段开始前已阅读：`docs/进度总览.md`、`docs/claude-memory.md`、`docs/设计参考.md`、`docs/产品呈现口径.md`、`docs/协作约定.md`。

## 目标

所有二级页面及更深层页面进入后，顶栏标题应展示当前页面标题，不再沿用默认「田园通」品牌标题。

## 背景

部分二级业务页复用 `FarmAppBar(showBack: true)` 时没有传入 `title`，导致页面已经进入「乡村集市 / 农机共享 / 惠农政策 / 乡村生活 / 数据看板」等二级页后，顶栏仍显示默认品牌名。详情页中，农机详情、动态详情和商品详情也缺少当前内容标题。

## 改动清单

- 更新 `FarmAppBar` 注释，明确二级及详情页应传入当前页面标题。
- 为以下二级页补充显式顶栏标题：
  - `/market`：`乡村集市`
  - `/machinery`：`农机共享`
  - `/policy`：`惠农政策`
  - `/life`：`乡村生活`
  - `/data`：`数据看板`
- 为以下详情页补充动态顶栏标题：
  - `/machinery/detail`：使用农机名称
  - `/publish/detail`：使用动态标题，缺失时回退 `动态详情`
  - `/market/product/:id`：使用商品标题
