> 工作单（spec + 可执行计划）。所属：板块体验优化（承接 53 农机页重构）。

## 一、目标（一句话）

- **A**：`AppSearchField` 共享组件落地 `widgets/common.dart`，集市/AI 会话列表/数据服务页假搜索框换成真搜索，农机页内联搜索框回抽到组件（单一标准）。
- **B**：新增 `/market/product/:id` 整页详情，点商品卡 `context.push` 进入，顶部图廊 + 商品介绍流式分区 + 卖家信息 + 吸底「加入合计」CTA。

## 二、背景

- **搜索框不统一**：农机页已是用户满意的「`R.sm`=8 方角 + 1.5px 描边 + 去阴影 + 方角品牌绿搜索钮」标准（见记忆 `feedback-input-small-radius`），但集市仍是旧的「999 胶囊 + 麦克风」假占位 Container（`market_page.dart:264 _searchBar`），不可输入、不跳转。22 处 TextField 散在 16 文件各自手搓，`common.dart` 无任何共享输入组件。
- **商品"详情"是薄 sheet**：`market_page.dart:624 _showProductDetail` 是 85% 高 `showModalBottomSheet`，只有图 + 标题 + 卖家 + 价格 + 加入合计，**没有商品介绍/库存/产地/卖家信息**，且全靠卡片+浮层堆叠——这正是用户说的"不想全用卡片，要商品介绍式详情页"。
- **后端早已就绪**：`GET /market/product/:id`（`product.controller.js:30 detail`）返回 `{id,title,category,description,price,unit,stock,images[],regionCode,createdAt,seller:{nickname,villageName,phone}}`；`GET /market/product/list` 已支持 `keyword`（`title contains`）。**全部复用，零后端改动。**

## 四、轨 A · 全局输入框组件化

### A1 · 新增 `AppSearchField`（`widgets/common.dart`）

固化农机标准为唯一来源：

```dart
class AppSearchField extends StatelessWidget {
  final TextEditingController controller;
  final String hintText;
  final ValueChanged<String>? onSubmitted;   // 回车 / 点搜索钮触发
  final VoidCallback? onClear;               // 可选，有文字时显示清除
  ...
}
```

样式硬约束（**禁**圆角胶囊/阴影/渐变）：
- 外层 `Container`：`AppColors.surface` 底、`BorderRadius.circular(R.sm)`(8)、`Border.all(AppColors.outlineVariant, 1.5)`、**无 boxShadow**。
- 聚焦态描边转 `AppColors.primary`（用 `Focus`/`FocusNode` 或直接 `TextField` 的 focusedBorder 不可见——外层描边需自管，用 `FocusNode` 监听切换 border 颜色）。
- 左 `Icons.search`(`AppColors.outline`)；内部 `TextField`：`filled:false` + `border/enabledBorder/focusedBorder` 全 `InputBorder.none`（去 Material 默认下划线）、`isCollapsed` 收紧。
- 右侧方角品牌绿「搜索」按钮（`AppColors.primary` 填充、`R.sm` 圆角、白字），点击 = `onSubmitted(controller.text)`。
- 高度约 52~56，与农机页一致。

> 实现可直接把 `machinery_page.dart` 现有搜索框那段抽过来作为蓝本。

### A2 · 各页替换

- **集市** `market_page.dart`：删 `_searchBar()` 假占位 → 用 `AppSearchField`；新增 `_keyword` controller，`onSubmitted` 调 `_loadProducts()`，`_loadProducts` 的 query 带上 `if (keyword.isNotEmpty) 'keyword': keyword`（list 已支持）。
- **农机** `machinery_page.dart`：把内联搜索框替换为 `AppSearchField`（**行为不变**，回抽消重，确保单一标准）。
- **AI 会话列表** `ai_threads_page.dart`、**数据服务页** `data_service_page.dart`：若顶部有搜索/过滤框，换成 `AppSearchField`（**保持原过滤逻辑**，仅换壳）；若只是本地过滤无伤大雅。
- 表单类（登录/注册/发布/设置）**本批不动**。

### A3 · `AppTextField`（表单标准，仅落组件、本批不铺）

定义方角描边表单输入组件作为下一批表单统一基准；**本段不替换任何表单**，避免大面积回归。
> YAGNI 提示：若本段没有任何调用点，则 A3 推迟到表单批次再建，避免死代码——**本段以 A1/A2 为准，A3 可不交付**。

## 五、轨 B · 集市商品整页详情

### B1 · 路由

`core/router.dart` 在 ShellRoute 内加（仿 `/market/service`，底栏因非一级 tab 不显示）：
```dart
GoRoute(path: '/market/product/:id',
  builder: (_, state) => ProductDetailPage(
    productId: int.tryParse(state.pathParameters['id'] ?? ''),
    preview: state.extra as ProductPreview?,   // 可选：列表已有的图/标题/价，先渲染避免白屏
  )),
```
- `market_page.dart` 商品卡 `onTap`：`_showProductDetail(sheet)` → `final qty = await context.push<int>('/market/product/${product.id}', extra: preview);` 拿回数量并入 `_cart`。
- `product.id == null`（示例数据）保持原 toast「商品资料更新中」，不跳转。

### B2 · 页面结构（`product_detail_page.dart`）—— **流式分区，非卡片堆**

`CustomScrollView`：

1. **`SliverAppBar`（图廊）**：`expandedHeight ≈ 300`、`pinned`，`flexibleSpace` = `PageView`(images[])。
   - 多图才显示底部圆点指示器；`images` 空 → 单张 fallback asset（沿用列表那套 `_4_x.jpg` 兜底）。
   - 回退箭头浮在图上（白色 + 半透明圆底，仅此处允许，属标准返回控件）。
2. **`SliverList` 正文**（`AppColors.background` 底，内容用 `SectionDivider` 发丝线分隔，**不套 `AppCard`**）：
   - **标题区**：`title`(w700 20) + 分类徽标 `StatusChip(category)`。
   - **价格区**：大红价 `￥{price}`(w800 28) + `/{unit}` + 右侧 `库存 {stock} {unit}`（stock=0 → 灰「暂时缺货」）。
   - **发丝分隔线**（`Divider(height:1, color: outlineVariant.withAlpha)`，非卡片）。
   - **「商品介绍」** `SectionTitle` + `description` 流式正文（`height:1.6`、`onSurfaceVariant`）。`description` 空 → 按 `category` 兜底文案（小 map：水果/蔬菜/畜禽/土特产/其他），**不露馅、不提"暂无"**。
   - **发丝分隔线**。
   - **「产地 · 溯源」** 信息行：`regionCode→地区名` + 溯源码（有则显示，无则只显产地）。**不另开溯源页**（本段不扩范围）。
   - **发丝分隔线**。
   - **「卖家」** 轻分组（头像 + `seller.nickname` + `villageName` + 「联系」）：**轻量行，不用重投影 `AppCard`**；点「联系」toast 出电话或复制（不打真实电话）。
3. **吸底操作栏**（`bottomNavigationBar` 或 `Stack` 底栏，`useRootNavigator` 概念不适用——这是整页非 sheet）：
   - 左：`￥{price}/{unit}`；右：方角品牌绿「加入合计」`ElevatedButton`。
   - 点击 → 弹数量选择（`showModalBottomSheet`，`useRootNavigator:true`，步进器 1~stock）→ 确认后 `context.pop(qty)` 把数量带回 `MarketPage`。
   - `stock==0` 或 `id==null` → 按钮禁用。

### B3 · 数据加载

- `initState` 调 `GET /market/product/:id`；加载中用 `preview`（列表传入的图/标题/价）先铺底，避免白屏；失败 `ErrorRetry`。
- 不接离线缓存（详情页即点即拉，简单优先；失败可重试）。

## 六、接口契约（全部已存在，禁新增/改后端）

| 用途 | 方法 路径 | 入参 | 出参要点 |

| 商品列表（带搜索） | `GET /market/product/list` | `pageSize,category?,keyword?` | `{records[],total}`；`keyword` = title contains |

## 七、产品口径 & 设计系统硬约束

- 文案**不得**出现「离线/断网/本地/单机/暂无数据」等词；失败走 `actionErrorMessage`/`serviceUnavailableMessage`。
- 主绿 `AppColors.primary`(0xFF0D631B)/大地棕/麦金/背景 `background`；圆角 `R.sm=8/md=16/lg=32`；阴影 `ambientShadow`（柔棕，禁纯黑）。
- **禁** generic 渐变（hero 图除外用真图）、半透明白浮层、脉冲光、圆角胶囊输入框。
- 详情页核心诉求：**流式分区 + 发丝分隔线 + 留白呼吸 + hero 图破边**，脱离"每块都套白卡阴影"。
