# 分段 85 — 个人界面 / 编辑资料分离 + 全字段可编辑

> 用户：「个人界面和编辑资料界面分开，编辑资料界面，什么都能编辑，包括头像、昵称、banner 图、账号、手机号等。」

把原 `account_page.dart`（视图+编辑混在一起）拆成**只读个人界面** + **独立编辑页**，
并补齐头像 / banner 上传与账号可改所需的后端能力。

## 一、后端改动

| 文件 | 改动 |
|---|---|
| `prisma/schema.prisma` | `User` 加 `bannerUrl String?`（个人资料封面） |
| `prisma/migrations/20260616100000_add_user_banner/migration.sql` | `ALTER TABLE "t_user" ADD COLUMN "bannerUrl"` |
| `src/modules/platform/user.controller.js` | `updateProfile` 放开 `username`（≥3 位、`[a-zA-Z0-9_]`、唯一校验）、`avatarUrl`、`bannerUrl`；新增 `uploadImage`（存盘回传 `{ url }`） |
| `src/modules/platform/platform.routes.js` | `POST /upload/image`（`requireAuth` + `upload.single('image')`，复用既有 multer 中间件） |
| `src/modules/platform/resource.config.js` | 用户资源 fields 加 `avatarUrl`/`bannerUrl`（管理台也可改） |

> 上传文件落 `backend/uploads/`（multer diskStorage，随机文件名），`/uploads` 已 express.static 暴露；
> 回传相对路径 `/uploads/<file>`，前端 `ApiClient.resolveImageUrl` 解析为完整地址。

## 四、验收

- 迁移 `migrate deploy` + `prisma generate`（停整条 `npm run dev` 树避免引擎 DLL 占用，见 [reference] 记忆）。
- 后端 `node --check` 全过；`flutter analyze lib` → `No issues found!`；`flutter test` 通过。
- 接口实测（farmer）：
  - `POST /upload/image`（multipart）→ `{ url: '/uploads/xxx.png' }`。
  - `PUT /user/profile {avatarUrl,bannerUrl}` → 持久化成功。
  - `PUT /user/profile {username:'admin'}` → `40001 该账号已被占用`（唯一校验生效）。
- 浏览器实测：
  - 个人界面（只读）：banner/头像/编辑资料按钮/名字/@账号/元信息/成长阶梯/账号资料只读行均正常。
  - 编辑页：banner「更换封面」、头像相机覆盖、**账号可编辑**、各字段、保存按钮齐备。
  - API 置真 avatar/banner 后回视图：`Image.network` 封面与头像正常渲染（验证后已复位 farmer 为 null）。
  - 控制台 0 error。

## 五、不在范围内

- 修改密码仍在独立子页（`/profile/settings/password`），不并入本编辑页。
- 头像/banner 旧文件清理（更换后不删旧文件）暂不做。
- 改账号后旧 JWT 仍有效（鉴权按 id，不受 username 变更影响）；下次登录用新账号。

## 六、补丁 — 头像/封面换不了（用户反馈）

排查：后端三条数据链路（`/upload/image`、`updateProfile` 放开 avatar/banner、`Image.network` 渲染）
均 curl + 浏览器验证可用；App 选图也会弹文件选择器。真正缺口在「反馈」与「管理台无上传控件」：

1. **管理台**：avatarUrl/bannerUrl 原是纯文本 URL 框，没有上传控件——管理员无从「换」图。
   - `resource.config.js`：两字段类型由 `string` 改为 `image`。
   - `admin/src/pages/ResourcePage.jsx`：新增字段类型 `image` → `ImageUploadField`（antd `Upload`
     `customRequest` → `POST /upload/image`，缩略图预览 + 「更换/清除」+ URL 兜底框）；`formatValue`
     对 image 字段渲染缩略图。vite 已代理 `/api` 与 `/uploads`，相对地址可直接预览。
   - 实测：编辑用户 → 头像「上传图片」→ 选图 → 缩略图渲染 + URL 自动回填 ✓。
2. **App**：选图上传成功后原本无任何提示，易被误判「没反应」。`account_edit_page.dart` 上传成功
   toast「头像/封面已更新，点保存生效」，失败 toast「上传失败，请重试」，URL 为空也提示。
