## 预期改动

### 根级验证脚本

新增 `scripts/verify-all.ps1`，按参数或默认顺序执行：

1. Flutter `pub get`、`analyze lib`、`test`。
2. Flutter Web debug build。
3. 后端全量 `node --check`。
4. 后端测试与 lint（脚本存在时执行，不存在时明确报告缺口）。
5. 管理台 build、测试与 lint（脚本存在时执行）。
6. 输出每个检查的退出码和最终汇总。

脚本不得静默吞掉失败；所有失败都要以非零退出码结束。

### Characterization tests

后续 M0 工作单应增加以下最小回归覆盖：

- 认证：注册、登录、token 失效、个人资料读取。
- 交易：商品列表、商品详情、订单列表和模拟支付状态。
- AI：规则回答、对话历史隔离、助手导航命令结构。
- 村级经营：ADMIN 全域、VILLAGE 本区域、普通角色拒绝。
- Flutter：启动、登录守卫、首页核心入口、订单状态显示。
- 管理台：登录、资源目录加载、核心状态命令入口。

测试必须使用独立 fixture/测试数据库，不得污染比赛演示库。
