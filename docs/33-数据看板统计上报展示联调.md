# 分段 33 — 数据看板最近统计上报展示联调

## 本次目标

继续做 Flutter App 后续体验优化与联调，优先修复数据看板中“最近统计上报”卡片的字段错位问题，让服务端返回结构与移动端展示保持一致。

## 问题定位

`/data/dashboard` 返回的 `latestStatReports` 来源于 `StatReport`：

- 统计类型字段为 `statType`
- 作物、面积、产量存放在 `dataJson`
- 状态字段为 `status`

移动端数据看板仍按旧字段读取：

- `reportType`
- `cropType`
- `areaMu`
- `yieldKg`

因此界面容易显示为“统计数据 · 综合 / 0 亩 / 0 公斤”，实际统计内容没有被正确呈现。

## 已完成内容

1. 调整 `backend/src/modules/data/dashboard.controller.js`
   - 引入 `parseJson`
   - 为 `latestStatReports` 增加 `normalizeStatReport`
   - 将 `dataJson` 解析为对象
   - 补齐 `cropType`、`areaMu`、`yieldKg` 便于前端直接展示
2. 调整 `app/lib/pages/data/data_dashboard_page.dart`
   - 最近统计上报标题改为读取 `statType`
   - 作物、面积、产量优先读取后端规整字段，兼容 `dataJson`
   - 增加统计状态中文映射：草稿 / 已上报 / 已确认
3. 使用 `dart format` 格式化 Flutter 变更文件。
