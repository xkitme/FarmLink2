# 80 · AI 聊天页历史图片回显修复 + 顶部场景切换条移除

> 状态：✅ 完成（Claude 实施，2026-06-16）
> 范围：`app/lib/pages/ai/ai_chat_page.dart`（纯前端，后端零改动）

## 目标

打开历史 AI 会话时，之前发给 AI 识别的图片能正常回显；同时按用户要求去掉聊天页顶部的场景切换条（综合 / 农技 / 政策 / 法律）。

## 背景

- **历史图片不显示**（用户反馈）：识图时图片以 `imageUrl` 存进了 `t_ai_qa_record.referencesJson`（`{ detect: {...,imageUrl}, imageUrl }`，见 `ai.controller.js:qaDetectRecord`）。列表页 `ai_threads_page.dart` 早已读它显示缩略图（docs/64 那批），但单会话页 `ai_chat_page.dart` 的 `_loadHistory` 重建消息时只取了 `question` 文本，丢掉了图片；且 `_ChatMessage`/`_userBubble` 只支持内存字节（`Image.memory`），不认网络 URL。
- **去场景条**（用户反馈，附截图）：顶部 ChoiceChip 行视觉占位，要求移除。

## 改动清单

`app/lib/pages/ai/ai_chat_page.dart`：

1. `_ChatMessage` 新增 `final String? imageUrl;`，构造参数与 `copyWith` 同步保留。
2. 新增 `_detectImageUrlFromRecord(record)`：与列表页同口径，按
   `referencesJson.imageUrl → referencesJson.detect.imageUrl → record.imageUrl` 取值，
   用 `ApiClient.resolveImageUrl` 解析为绝对地址，无图返回 null。
3. `_loadHistory` 重建 user 消息时挂上该 `imageUrl`。
4. 新增 `_bubbleImageProvider(msg)`：实时发送走 `MemoryImage`，历史回显走 `NetworkImage`。
5. `_userBubble` 用上述 provider 渲染图片，加 `loadingBuilder`（转圈）/`errorBuilder`（破图占位）。
6. `_showImagePreview` 改为接收 `ImageProvider`（内存图 / 网络图都能点开大图预览）。
7. 移除 `_sceneBar()` 方法及其在 `build` 里的调用。`_scene` 字段保留（发送 scene 字段 + 输入框占位提示用），现固定取进入页面时的初始场景。

## 接口契约

无新增/变更。复用既有：
- `GET /ai/qa/threads/:threadId` → `{ records: [...] }`，每条含完整 `referencesJson`。
- `ApiClient.resolveImageUrl(value)`：相对路径按 `baseUrl` 解析为绝对 URL。
