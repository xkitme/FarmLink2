# 分段 45c — 村级数字驾驶舱大屏（招牌场景 A2）

> 工作单（Codex 实施）。所属 lane：[45-招牌场景与产品重构计划](45-招牌场景与产品重构计划.md) Lane A · A2。
> demo 高光镜头之二：村委办公室显示器挂的实时数据大屏。
> **复用 `GET /data/dashboard`，不新增后端接口。**

## 一、目标

村委账号登录后，进入 `/screen` 全屏深色科技风数据大屏，自动轮询刷新，
展示该村农情 / 灾情 / 集市 / AI 服务实时数据。演示时一个长镜头扫过去就够震撼。

## 二、关于「公开 H5」的简化

原 plan 设想「公开链接免登录」。**本段简化为「村委登录后全屏展示」**：

- 不动后端 auth，不加免登录公开接口
- demo 时村委账号已登录，直接开 `/screen` tab → 复用当前 token 拉 dashboard
- regionCode 由村委账号自动决定（VILLAGE 角色后端按 regionCode 行级过滤）

对评委看到的画面无任何损失（看到的就是实时大屏）。真要做公开免登录链接，留到后续单独加只读接口。

## 四、改动清单

### 1. 新建 `app/lib/pages/screen/village_screen_page.dart`

要点：

- `StatefulWidget` + `Timer.periodic` 每 **30 秒** 轮询 `GET /data/dashboard`
- 进入 `WakelockPlus`（如果项目已有该依赖则用，没有就不加，避免引新依赖）保持屏幕常亮 —— **可选，没有依赖就跳过**
- 顶栏实时时钟：另一个 `Timer.periodic` 每秒更新 `DateTime.now()`
- 全屏深色背景，`SafeArea` + 自适应 `LayoutBuilder`（宽屏 4 列，窄屏 2 列）
- 数据映射（全部来自 `/data/dashboard` 的现有字段）：

  | 卡片 | dashboard 字段 |
  |---|---|
  | 地块面积 | `cards.totalAreaMu` |
  | 农事记录 | `cards.recordCount` |
  | AI 服务调用 | `cards.aiCallCount` |
  | 灾情预警 | `cards.disasterCount` |
  | 用户数 | `cards.userCount` |
  | 商品 / 订单 / 成交额 | `cards.productCount` / `cards.orderCount` / `cards.orderAmount` |
  | 种植结构柱图 | `cropArea[]`（cropType + areaMu） |
  | 灾情列表 | `disasterStats[]`（type + loss） |
  | 同步状态 | `latestSyncLogs[]` |

  > 字段以 `data_dashboard_page.dart` 现有解析为准（已经在用这些字段），直接照搬 `_map/_list/_int/_num` helper。

代码骨架：

```dart
class VillageScreenPage extends StatefulWidget {
  const VillageScreenPage({super.key});
  @override
  State<VillageScreenPage> createState() => _VillageScreenPageState();
}

class _VillageScreenPageState extends State<VillageScreenPage> {
  Timer? _pollTimer;
  Timer? _clockTimer;
  Map<String, dynamic> _dashboard = {};
  DateTime _now = DateTime.now();
  bool _loading = true;

  static const _bg = Color(0xFF0B1F12);
  static const _panel = Color(0xFF12301C);
  static const _leaf = Color(0xFF88D982);
  static const _gold = Color(0xFFFFBA38);

  @override
  void initState() {
    super.initState();
    _load();
    _pollTimer = Timer.periodic(const Duration(seconds: 30), (_) => _load());
    _clockTimer = Timer.periodic(const Duration(seconds: 1), (_) {
      if (mounted) setState(() => _now = DateTime.now());
    });
  }

  @override
  void dispose() {
    _pollTimer?.cancel();
    _clockTimer?.cancel();
    super.dispose();
  }

  Future<void> _load() async {
    try {
      final data = await ApiClient.get('/data/dashboard');
      if (!mounted) return;
      setState(() {
        _dashboard = data is Map ? data.cast<String, dynamic>() : {};
        _loading = false;
      });
    } catch (_) {
      if (mounted) setState(() => _loading = false);
      // 大屏静默重试（下个轮询周期再拉），不弹错
    }
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      backgroundColor: _bg,
      body: SafeArea(
        child: _loading
            ? const Center(child: CircularProgressIndicator(color: _leaf))
            : Padding(
                padding: const EdgeInsets.all(20),
                child: Column(
                  children: [
                    _topBar(),
                    const SizedBox(height: 16),
                    Expanded(child: _grid()),
                  ],
                ),
              ),
      ),
    );
  }
  // _topBar / _grid / _bigStatCard / _cropBar / _disasterList / _aiStatus ...
}
```

- `_topBar`：左「🌾 {villageName} · 数字乡村驾驶舱」+ 右实时时钟（`DateFormat('yyyy-MM-dd HH:mm:ss')`）
- `_grid`：`LayoutBuilder` 宽 > 900 用 4 列大数字 + 2×2 图表区；窄屏退化 2 列
- `_bigStatCard`：深色面板 + 大号叶绿数字 + 麦金标签，数字用 `AnimatedSwitcher` 或简单 setState 刷新
- `_cropBar`：复用 `home_page` 的柱图思路，深色配色
- `_disasterList`：灾情滚动（数据多时用 `ListView` 自动；可选加 `AnimatedList` 轮播）
- `villageName` 从 `context.read<AuthState>().user?.villageName ?? '示范村'`

### 2. 路由 `app/lib/core/router.dart`

`/screen` 放在 **ShellRoute 之外**（全屏无底栏），但在登录守卫之内（需登录）：

```dart
// 顶层 routes（与 /splash /auth 同级，不在 ShellRoute 里）
GoRoute(path: '/screen', builder: (_, __) => const VillageScreenPage()),
```

redirect 逻辑不变（未登录访问 `/screen` → 跳 login）。已登录可直接访问。

### 3. 入口

- **数据看板页** `data_dashboard_page.dart` AppBar 加一个「全屏大屏」按钮（`Icons.fullscreen`）→ `context.go('/screen')`
- 大屏页角落加一个小的「退出」按钮（`Icons.close`）→ `context.go('/data')`，避免全屏出不来

### 4. 后端

**不新增**。复用 `GET /data/dashboard`（VILLAGE 角色已按 regionCode 行级过滤）。

## 五、验收

1. `flutter analyze lib/pages/screen lib/core/router.dart` → No issues
2. 用 village 账号登录 → 数据看板点「全屏大屏」→ 进入 `/screen`
3. 顶栏时钟每秒跳动；30 秒后台数据自动刷新（可改后端数据后等 30s 看大屏变化）
4. 4 个大数字卡 + 种植结构柱图 + 灾情列表 + AI 状态都有真实数据（来自 45a 种子）
5. 宽屏（浏览器拉宽）4 列布局；窄屏 2 列不溢出
6. 角落「退出」→ 回数据看板
7. 后端临时停掉 → 大屏不崩（保留上次数据，静默等下次轮询）

## 六、不在范围内

- 不做公开免登录链接（需后端只读接口，留后续）
- 不引入图表依赖（fl_chart 等）—— 用手绘柱图/进度条，与现有 home 柱图同风格
- 不做大屏端的交互钻取（点卡片下钻），纯展示
- 不做多村切换（regionCode 固定为当前村委账号的村）
- WakelockPlus 仅在项目已有依赖时用，否则跳过
