# 田园通 · FarmLink

> **数字乡村助农平台** —— 围绕「乡村振兴」战略与「数字乡村」建设方针，
> 为农户日常生产、经营、生活提供一站式数字化服务。
> 核心理念：**离线优先 · 本地 AI 赋能 · 完整可独立部署**。

---

## 一、项目简介

田园通（FarmLink）是一套面向乡村的综合数字化平台，覆盖农业生产、农产品流通、
农机共享、气象灾害、惠农政策、乡村生活、数据管理等 **8 大板块、76 个功能模块**，
其中 **24 个模块融合 AI 能力**。

平台针对农村网络条件设计，**核心功能在断网状态下依然可用**：本地 SQLite 数据库、
离线同步队列、本地 AI 模型兜底，联网时云端增强。整套系统无需 Docker、无需外网，
拿到完整项目包即可在一台普通笔记本（如 RTX 5060 Laptop / 8GB 显存）上独立运行。

### 组成部分

| 端 | 说明 | 技术 |
|---|---|---|
| **后端服务** | 76 模块业务 API + 本地 AI 编排 | Node.js + Express + Prisma + SQLite |
| **管理面板** | 数据管理、API 开关、在线调试、系统监控 | Ant Design Pro（React + Vite） |
| **移动端 App** | 农户使用的主应用，可打包 Android APK | Flutter |

## 二、核心特点

- **8 大板块 76 个功能模块**，全部可运行，覆盖农业生产到乡村生活全场景
- **24 个 AI 融合模块**：病虫害识别、政策问答、产量预测、智能匹配等，
  基于本地 Ollama 模型，离线可用、不依赖外网
- **离线优先架构**：SQLite 本地库 + 离线缓存 + 同步队列，断网照常记录、联网自动补传
- **完整管理后台**：业务数据增删改查、API 功能开关、API 在线调试、限流、操作日志、
  AI 配置、离线同步记录、种子数据管理
- **思政融入**：惠农政策推送、党建学习打卡、文明乡风榜、乡村振兴积分等模块
  紧扣国家乡村振兴战略
- **统一设计语言**：移动端采用「Agro-Modernist Tech」农业现代科技风设计系统
- **轻量可交付**：SQLite 单文件数据库，无 Docker 依赖，完整项目包即可独立部署运行

## 四、技术架构

```
┌──────────────────────────────────────────────┐
│  移动端 App (Flutter)        管理面板 (Ant Design Pro) │
│  农户主应用，可打包 APK        数据/开关/调试/监控       │
└───────────────────┬──────────────────────────┘
                    │  HTTP / SSE  /api/v1
┌───────────────────▼──────────────────────────┐
│           后端服务 (Node.js + Express)         │
│  9 业务模块 · 统一响应 · JWT 鉴权 · API 开关 · 限流  │
├───────────────────┬──────────────────────────┤
│   Prisma ORM      │      本地 AI 编排           │
│   SQLite 单文件库  │  Ollama + SQLite 向量 RAG  │
└───────────────────┴──────────────────────────┘
```

### 技术选型

| 层 | 选型 | 说明 |
|---|---|---|
| 后端框架 | Node.js + Express（ESM） | 轻量、启动快、易部署 |
| ORM | Prisma 5 | 类型安全，迁移管理 |
| 数据库 | SQLite | 单文件、免安装、可断网，60 张表 |
| AI 运行时 | Ollama 本地模型 | qwen2.5（问答）/ bge-m3（向量）/ minicpm-v（图像） |
| 鉴权 | JWT 双 Token | access 2h + refresh 30d |
| 管理面板 | Ant Design Pro · React 18 · Vite | 数据中后台 |
| 移动端 | Flutter 3 | 一套代码，Android APK + Web 预览 |
| 状态管理 | Provider（移动端） | 登录态、离线状态 |
| 路由 | go_router（移动端） | 声明式路由 + 登录守卫 |

### 关键设计

- **统一响应格式**：`{ code, msg, data, timestamp, traceId }`
- **错误码**：200 成功 / 40001 参数错 / 40101 未登录 / 40301 无权限 /
  40401 不存在 / 42901 限流 / 50001 服务器错 / 60001 AI 繁忙 / 60002 离线降级
- **角色体系**：FARMER 农户 / BIGFARMER 大户 / VILLAGE 村委 / EXPERT 农技员 /
  MERCHANT 商家 / ADMIN 管理员，村委按 `regionCode` 行级数据隔离
- **离线同步**：业务表带 `localUuid`，断网写本地队列，联网按时间戳回放、冲突检测
- **AI 兜底链路**：Ollama 在线 → 本地 SQLite 向量 RAG → 规则库，逐级降级保证可用

## 六、快速开始

### 环境要求

- Node.js 18+
- Flutter 3.3+（如需构建移动端）
- Ollama（可选，用于 AI 增强；未启动时自动走本地规则兜底）

### 1. 首次准备依赖

```powershell
cd backend
npm run install:all      # 安装后端 + 管理面板依赖
npm run db:migrate       # 初始化 SQLite 数据库
npm run db:seed          # 写入种子数据
```

移动端首次运行前：

```powershell
cd app
flutter pub get
```

### 2. 一键启动全部本机服务

在项目根目录运行一条命令：

```powershell
.\start.bat
```

等价 PowerShell 命令：

```powershell
.\scripts\start-local.ps1
```

脚本会自动启动：

- 后端 API：`http://localhost:8000/api/v1`
- 管理面板：`http://localhost:5173/admin/`
- 移动端 Web：`http://localhost:5000`

日志输出在 `.runtime/`。再次执行 `.\start.bat` 会先清理占用的默认端口再重新启动。

常用参数：

```powershell
.\start.bat -SkipWebBuild
.\start.bat -BackendPort 8000 -AdminPort 5173 -WebPort 5000
.\start.bat -SkipAdmin
.\start.bat -SkipMobile
```

### 3. 构建 Android APK

真机安装时后端地址需填写电脑在局域网中的 IP：

```powershell
.\scripts\build-apk.ps1 -ApiBaseUrl "http://192.168.1.10:8000" -Mode release
```

构建产物输出到 `dist/FarmLink.apk`。

## 八、AI 能力说明

平台 AI 全部本地运行，**不依赖外网**：

| 场景 | 在线（Ollama 已启动） | 离线兜底 |
|---|---|---|
| 政策/农技/法律问答 | qwen2.5 + SQLite 向量 RAG | n-gram 检索知识库 + 规则库 |
| 病虫害/杂草/种子识别 | minicpm-v 视觉模型 | 知识库匹配 + 置信度估算 |
| 产量预测 / 智能匹配 / 文案生成 | 模型增强 | 规则模型 / 模板 |

未安装 Ollama 时后端会自动降级，所有 AI 接口仍可返回可用结果。

## 九、离线优先设计

- **本地数据库**：SQLite 单文件，整库随项目包分发
- **离线缓存**：移动端各业务列表带本地缓存，断网展示最近数据并提示
- **同步队列**：断网下的写操作（农事记录、灾情上报、发布动态等）写入本地队列，
  联网后按时间戳回放，服务端基于 `updatedAt` 做冲突检测
- **AI 兜底**：模型不可用时逐级降级到规则库，保证功能不中断
